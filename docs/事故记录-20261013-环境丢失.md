## 七、教训与防复发（本次优化目标）
1. **升级=危险动作**：任何升级/大版本变更**先问主公**，且**升级前先做一次即时备份**（不能只依赖夜间备份）。
2. **升级要能自证成功**：升级后必须验证 `openclaw --version`、`config validate`、`agents list`、`channels status`；失败要能回滚。
3. **网关内存要有护栏**：加 systemd drop-in 限流，让"崩"只崩网关、不拖垮整机（且保留 Restart=always 自愈）。
4. **别把全体管家指向计费套餐**：GLM 只做"审查员"单点调用；并加额度守卫（429 → 自动回落 + 告警）。
5. **卡死会话说"停"**：给 agent run 设重试上限/超时，禁止无限重试。
6. **备份三层都要活着**：本地 L0 已 OK，但 git push 到群晖失败 → 灾备是断的，必须修。
7. **密钥别明文**：4 处明文密钥要改成 SecretRef。
