## 3. 成本与定价（模板，等耗材价填）
- 单件成本 = 材料克重 × 单价 + 电费（约 0.1 元/小时）+ 损耗 10%
- 定价 = 成本 × 3（零售）/ × 2（同行批量），教学衍生件可按「套」卖
- 报价单自动生成：给参数（材料/克重/时长/数量）即出价

## 4. 流水线（我能自动化的部分）
1. 订单登记 → 建任务（账本）
2. 模型检查（壁厚/悬空/尺寸）→ 切片参数模板
3. 排队打印（按耗时与材料分组，避免频繁换料）
4. 成品拍照 + 归档（STL/参数/成本三件套）
5. 复购清单与库存扣减

## 5. 试产一周计划（等设备到）
- D1 校准：首层、流量、尺寸精度（打印 20mm 立方 + 公差测试件）
- D2-D3 打样 3 个 SKU，记录失败点
- D4 成本实测，定价定稿
- D5 拍成品照，上架（朋友圈/闲鱼/同行群）
- D6-D7 接首批订单，跑一轮完整流水线

## 6. 需要主公提供

3. 想要的第一个「自家用」件（我从这个开始建模，最快出成果）

## 7. 要不要单设「3D 打印管家」（结论：现在不要）
- 现状：36 个 agent，13 个 7 天零交互，5 个从未开工；cron 名额 100/100 已满。再建一个大概率变空壳。
- 3D 这摊 90% 是文件与数据活（参数、切片档案、成本、报价、库存、订单），果果 + 干活管家现成能力足够。
- 现分工：果果（产线/成本/台账/汇报）｜work（建模辅助/批量切片/失败归因）｜格格（说明书与包装印刷）｜主公（换料/拆支撑/清堵头/验收）。
- **建管家阈值（满足任一）**：周订单 ≥10 单｜SKU 库 ≥30 个｜需要对外接单客服。到那时再建 `maker`，并同步腾出 cron 位。
