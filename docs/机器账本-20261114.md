## 二、一句话对照（最容易混的三个）
- **MyPC-Node = B 机** = 主公 Windows 台式机
- **C-Library = C 机** = 媒体库/仓库 PC（192.168.1.106）
- **library / 库房 / 仓库** 这类词一律指 **C 机**，不是 B 机

## 三、怎么现场确认（别靠记忆）
```
openclaw nodes list --json | python3 -c "import json,sys;[print(n['displayName'],n.get('connected')) for n in json.load(sys.stdin)['paired']]"
ping -c1 -W1 192.168.1.106   # C 机在不在
ping -c1 -W1 192.168.1.107   # B 机在不在
ping -c1 -W1 192.168.1.109   # NAS 在不在
```
节点名（displayName）是稳定标识；IP 会漂，**以节点名为准，IP 只做当次连接用**。

## 四、纪律
- 任何管家汇报、写日志、写文档，机器一律写代号（A/B/C/D/E/NAS），首次出现可带全名
- 新增机器先改本表再启用，不许口头起名
- 本表与 CLAUDE/AGENTS 冲突时，以本表为准并回头改指针
