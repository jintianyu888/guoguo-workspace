## 一、我自己的脚本（~/.openclaw/workspace/tools/，64 个）

### 备份 / 恢复
- `backup-drill.sh` 备份演练：查四条备份层是否真在工作
- `backup-report.sh` 出备份现状报告（最新归档/群晖副本/保留份数）
- `backup-manage.sh` · `backup-prune.py` · `backup-space.sh` 保留策略与占用统计
- `nas-push-archive.sh` 全量归档推群晖 · `nas-sync-repos.py` 22 个工作区镜像到群晖
- `nas-git-push.sh` git 备份推群晖 · `nas-storage.py` · `nas-repo-report.py` 群晖空间报告
- `local-disk-copy.sh` 本机第二份备份 · `encrypt-ssh-backup.sh` 给 .ssh 备份加密

### 告警 / 自检
- `health-alert.sh` 每 20 分钟哨兵：备份失败/超期、硬盘>90%、公网入口意外开、明文密钥
- `daily-selfcheck.sh` 每日系统自检 · `automations-audit.py` 查定时任务报错
- `agent-capability-audit.py` 能力矩阵筛查 · `asset-audit.py` 资产清单+变更比对
- `openclaw-health.sh` 网关健康

### 打印
- `print.py` 送印东芝打印机（192.168.1.80:9100）· `print-prep.py` 打印前处理（统一 A4）

### OCR / 语音（都本地跑，零 API 成本）
- `ocr-file` · `ocr.py` 图片/PDF 转文字 · `asr` · `whisper-wrapper.py` 语音转文字

### 文件搬运
- `inbox-sync.sh` 每小时扫群晖投递区拉给对应管家
- `pack.py` 打包给主人（超 20MB 自动分卷）· `unpack.py` 解压
- `trash-add.sh` · `trash-roll.sh` · `trash-report.sh` 回收站（不硬删）

### 记账 / 台账
- `ds-balance.sh` DeepSeek 余额 · `agent-usage.sh` 各管家用量台账
- `usage-snapshot.sh` 每日用量快照 · `usage_by_model.py` 按模型统计
- `peak-status.sh` 是否优惠时段 · `host-peak-report.sh` 整机 CPU/内存峰值

### 日程 / 提醒 / 工具
- `schedule-hub-sync.py` 日程汇总 · `pending-add.sh` 加待办 · `holiday-check.py` 节假日
- `otp.sh` 一次性验证码 · `footer.sh` · `elapsed.sh` 页脚统计 · `compact-if-large.py` 自动压缩
- `work-queue.py` · `inbox-check.py` · `net-watch.py` · `load-gate.py` · `send-mail.py`
- `wecom-*.sh` 企微配置自检 · `agent-replies-since.py` 管家回复统计
