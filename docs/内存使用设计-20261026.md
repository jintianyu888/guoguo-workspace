# 内存使用设计（2026-10-26 夜）

## 一、实测基线
| 项 | 当前值 |
|---|---|
| 主机物理内存 | 32GB（周四/五升级 64GB） |
| WSL 配额 | memory=20GB · processors=14 · swap=12GB（X: SSD）· autoMemoryReclaim=gradual |
| WSL 实际 | 总 19GB · 已用 9GB · buff/cache 8GB · swap 用 2/12GB |
| 网关 cgroup | high 7.0G · max 10G · 当前 6.75G · 峰值 7.52G |
| 网关进程 | node RSS 6.15G（--max-old-space-size=6144） |
| **high 命中** | **100,794 次**（← 卡顿真因） |
| OOM | 0 次（硬限从未触发） |
| 其他大户 | clamd 984MB · openclaw 助手×2 523MB · ffmpeg×2 453MB |

## 二、问题定位
堆上限 6144MB + Node 原生开销 ≈ 7.0–7.5G，**正好压在 7G 软限上**。
结果：每分钟踩线 → 内核限流 → 事件循环卡顿 → 各管家回复被闸门卡住（实测 admit 30 秒）。
不是内存不够，是**预算配错**：软限贴着实际峰值，等于自己给自己上枷锁。

## 三、设计原则
1. **三层预算**：Windows / WSL / 网关，逐层留 15–25% 余量，任何一层打满都不殃及下层。
2. **软限必须高于实际峰值 30%**：软限是"限流线"，不是"目标线"；贴着峰值设必然长期限流。
3. **硬限兜底，不参与日常**：只在失控时防炸，正常永远不该碰到。
4. **堆上限 ≈ 软限 − 1.5G**（给 Node 原生/缓冲区留空间）。
5. **可观测**：所有阈值配采样与告警，不靠事后猜。

## 四、阶段一：现在（32GB 主机，WSL 20GB）
| 参数 | 现值 | 新值 | 理由 |
|---|---|---|---|
| .wslconfig memory | 20GB | **22GB** | 32−22=10GB 留给 Windows |
| Gateway MemoryHigh | 7G | **9G** | 高于峰值 7.52G 约 20%，不再天天限流 |
| Gateway MemoryMax | 10G | **12G** | 硬限兜底，WSL 22G 内安全 |
| Node heap | 6144 | **7168** | 7G 堆 + 1.2G 原生 ≈ 8.2G < 9G 软限 |
| swap | 12GB | 12GB | 不动（X: SSD，够用） |
| clamd | 常驻 984MB | **改按需 clamscan** | 一次省 ~1GB，扫描频率本来只有周扫 |

**效果预期**：high 命中从 10 万次/日 → 接近 0；管家回复不再被闸门卡；RSS 预计稳定在 7–8G。

## 五、阶段二：升级 64GB 后（WSL 48GB）
| 参数 | 新值 | 理由 |
|---|---|---|
| .wslconfig memory | **48GB** | 64−48=16GB 给 Windows |
| processors | 14 → **20** | 升级后可给更多核（视实际核心数） |
| Gateway MemoryHigh | **16G** | 为 35 个管家 + 更多并发留余量 |
| Gateway MemoryMax | **24G** | 硬限兜底 |
| Node heap | **14336**（14G） | 14G 堆 + 2G 原生 ≈ 16G |
| swap | **16GB** | 相应放大 |

**收益**：可安全并发更多模型调用、支持更长上下文、多管家同时干活不再互相挤。

## 六、配套机制（两阶段共用）
1. **内存采样**：每分钟记录 RSS/宿余量到 `state/memory/trend.csv`，保留 90 天。
2. **分级告警**：达软限 75% → 提示；90% → 告警；95% 持续 10 分钟 → 走正规重启路径（带窗口保护 + 2 小时退避）。
3. **会话回收**：空闲 >12 小时的会话自动关闭；上下文达 120K 触发压缩。
4. **大户治理**：clamd 按需化；ffmpeg/NVR 类任务限并发 2；模型长调用走后台单元不占主循环。
5. **周报**：每周一附内存趋势（均值/峰值/软限命中次数），异常才告警。

## 七、验收标准
- 软限命中次数 **< 100 次/日**（当前 10 万+）
- 网关 RSS 稳定区间内波动，无单调上升（判 leak）
- 各管家回复延迟 P95 < 5 秒
- 连续 7 天无 OOM、无人工重启
