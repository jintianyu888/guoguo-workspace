## 2026-10-26 审查（果果，只读分析，未改配置）

### 运行面
- security-patrol.service：oneshot，`--once --once-seconds 60`，MemoryMax=1G，CPUQuota=50%，Nice=10，TimeoutStartSec 有限；每 10 分钟由 timer 触发，Persistent=false。
- security-scan.service：oneshot，每日 06:30（避开 04:00–06:05 断网窗、07:00/07:15 巡检），跑 `tools/nvr-scan-daily.sh`，MemoryMax=3G，CPUQuota=200%，Nice=10。
- security-cleanup.service：安防事件库保留 90 天清理。
- **均为用户级（以 j 身份运行），无 root、无 sudo、无提权调用** ✅

### 脚本风险面
- `tools/security-patrol.py`：仅在 /tmp 建 `patrol-<ch>` 临时目录，用 `subprocess.Popen` 调 ffmpeg（未见 shell=True），无外联 HTTP。
- `tools/nvr-scan-daily.sh`：临时目录在 `state/tmp/nvr_isapi`（工作区内），带 flock 单实例；外联仅到 NVR 内网地址。
- `tools/security/cleanup-events.py`：按数据库里的绝对路径 `os.remove`。**缺路径归属校验**——若 DB 被污染可删任意文件（中风险）。

### 待批加固（systemd 层面，需主公点头）
`~/.config/systemd/user/security-patrol.service.d/10-harden.conf`（scan 同款）：
```
[Service]
NoNewPrivileges=yes
PrivateTmp=yes
ProtectKernelTunables=yes
ProtectControlGroups=yes
RestrictSUIDSGID=yes
LockPersonality=yes
```
- 用 drop-in 而非改原 unit，可一键删除回滚。
- 不加 ProtectHome/ProtectSystem（会挡住 workspace 与 /mnt 写入）。
- `cleanup-events.py` 增加前缀校验：删除前要求 `realpath` 位于 `state/faces/` 之下，否则跳过并计数。

### 结论
两项 timer **保持运行**（双审条件 GO 已满足）；加固项待批后执行。
