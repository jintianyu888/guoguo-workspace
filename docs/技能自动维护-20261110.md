# 技能库自动维护与自动测试（2026-11-10 主公令）

主公要求：技能要定期检查、优化、锤炼，保持自动进步、自动升级、自动测试。
落地＝一条零 token 的定时流水线，不占 cron 配额（cron 已 100/100 满额）。

## 每天 21:10 自动跑（systemd user timer）

单元：`oc-skill-maintain.timer` → `oc-skill-maintain.service` → `tools/skill-maintain.py`

顺序：
1. **自愈**：`tools/skill-mirror.sh` 把共享主本镜像到 main 实际加载的 workshop 副本（副本优先级高于 extraDirs，不镜像就会一直读旧版）。
2. **自测补齐**：`tools/skill-bootstrap-tests.py` 给没有 `selftest.sh` 的技能生成通用自检（引用脚本存在 + python 语法可解析）。
3. **体检**：`tools/skill-lint.py` 查 frontmatter/命名/摘要长度/引用路径与工具是否还存在。
4. **实测**：`tools/skill-selftest.py` 跑每个技能目录下的 `selftest.sh`，rc=0 才算通过（45 秒超时）。
5. **盘点**：`tools/skill-audit.py` 算未使用天数（按首见日）、45 天退休候选、共享主本与副本漂移。
6. **告警**：只报「新增或变化」的问题；已恢复的报一行；周日附全量周报。写入 `state/skills/health.json`。

## 判定口径

- 硬错误（会告警）：frontmatter 缺失、name 与目录名不符、description < 20 字、正文引用的路径或 tools 脚本不存在。
- 提示（不告警）：缺触发场景/步骤/验证/回滚节、篇幅过薄。
- 退休：首见日或最后使用日距今 ≥ 45 天且从未使用 → 候选，交主公定，不自动删。
- 自检覆盖：有 selftest.sh 才算覆盖。2026-11-10 起 24/24 全覆盖（15 份实机检查 + 9 份配置/守卫检查）；新增技能自动补通用自检，有真实故障历史的优先改成专项检查。

## 手动用法

```bash
python3 tools/skill-maintain.py --dry          # 只看不动、不发通知
python3 tools/skill-audit.py                   # 盘点/退休候选/漂移
python3 tools/skill-lint.py [--fix] [--json]   # 体检，--fix 只补 version/updated
python3 tools/skill-selftest.py [--only a,b]   # 跑自检
python3 tools/skill-bootstrap-tests.py         # 补通用自检
bash tools/skill-mirror.sh                     # 手动镜像
systemctl --user list-timers oc-skill-maintain.timer
```

## 写一份真自检（推荐）

技能目录下建 `selftest.sh`，退出码 0 = 现在真能用。要求：≤45 秒、无外部写、可重复跑。
例：打印技能验打印机 631 可达；ASR 技能验服务活着 + 端口响应；回收站技能验 NAS 目录可写。
