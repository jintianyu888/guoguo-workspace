# 外网访问与代理（2026-11-15 实测通过）

## 一、链路
```
慢头云客户端 (mantouyun-core.exe) 监听 127.0.0.1:7890
  → netsh portproxy 0.0.0.0:7891 → 127.0.0.1:7890（管理员执行，持久）
  → WSL 用 http://172.18.240.1:7891 访问（172.18.240.1 是 WSL 默认网关）
```
- 客户端里的「允许局域网连接」开关当前没生效（仍只绑 127.0.0.1），所以用 portproxy 兜住
- 落地脚本：C:\Users\Public\proxy-lan.bat（含防火墙放行 OpenClaw proxy 7891）
- 回滚：`netsh interface portproxy delete v4tov4 listenport=7891 listenaddress=0.0.0.0` + 删防火墙规则

## 二、用法
- 环境变量：`source tools/proxy-env.sh`（自动填 172.18.240.1:7891，no_proxy 已含内网与国内域名）
- 抓网页：`bash tools/fetch-web.sh <url> [out.html] [--text]`
- 自检：`bash tools/proxy-env.sh --check` → google=200
- ~/.bashrc 已加守卫块：代理端口在就自动启用，不在就静默跳过

## 三、验证记录
- curl -x ...:7891 https://www.google.com → 200（0.54s）
- youtube 200 / github 200 / hoffmanacademy 934KB 200

## 四、已知限制
- 网关自带的 web_fetch 仍不可用：本地 DNS 被污染（google 解析到内网地址被安全策略拦），必须走 fetch-web.sh（curl+代理，远端解析）
- 慢头云客户端退出后 7890 关闭，代理即失效；要常开
- portproxy 需要管理员添加；重启不丢，但批量重装系统后要重跑 proxy-lan.bat
