# 风险分级路由（L1 / L2 / L3）

> 目的：把「一刀切双审」换成按风险分档，省 token、省等待，同时不降低安全线。
> 落地：与 USER.md 的授权条款配套；判断口径写死，不靠临场感觉。

## 分档标准

| 等级 | 判据（命中任一即入档） | 验证方式 | 谁批 |
|---|---|---|---|
| **L1 低风险** | 只读诊断、查询、日志、状态采集；写自建工作区内的文档/脚本草稿；重启单个非关键服务以外的常规维护；可一键回滚且影响面限于果果自建物 | **单次自审**（自查证据+回滚点），做完报备 | 果果自决 |
| **L2 中风险** | 改脚本/流程/配置（非网关、非 systemd、非权限）；cron 增改；备份链参数；看板/报告输出格式；涉及主公个人数据之外的批量整理 | **双审**：两家不同厂商，必须真跑完，结论一致才动 | 果果自决后报备 |
| **L3 高风险** | 网关重启/停机、systemd/cgroup/内存上限、权限与白名单、密钥迁移与轮换、防火墙/端口暴露、备份删除与保留策略变更、升级、影响面跨机器 | **三审**：三家不同厂商，任一否决即停 | 果果自决后报备；不可逆项（批量删除/生物特征/密钥明文录入/采购）仍须主公点头 |

## 加速条款（省 token 的关键）

1. **同型复用**：同一类改动 7 天内已通过 L2 双审、且本次差异仅是参数值的，可降级为 L1 自审（记台账）。
2. **证据包优先**：给评审的输入必须是「文件:行号:原文」，不是文件名+大小；缺证据的评审结论按未通过处理。
3. **并行不串行**：L3 三审同时发三家，不排队；任一家超时按未跑完重跑，不算通过。
4. **不重复评审**：同一方案同一版本不重复送审；改动后只评审差异段。
5. **紧急降级**：主公示紧急时，L3 可先斩后奏，但事后 24h 内补审并留回滚点。

## 禁止降级（永远按 L3）

- 删除类（备份/归档/回收站/批量文件）
- 凭据（录入、迁移、轮换、外发）
- 权限与账号（白名单、channel 绑定、tool policy 放宽）
- 对外发送（邮件、群消息、发布）
- 花钱（采购、订阅、充值）

## 记录要求

每次 L2/L3 在 docs/交叉验证台账.md 追加一行：时间 / 事项 / 模型与结论（含字数或 rc）/ 结果 / 回滚点。
