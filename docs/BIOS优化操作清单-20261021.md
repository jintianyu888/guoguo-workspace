# BIOS 优化操作清单（MSI MAG X670E TOMAHAWK WIFI · BIOS 1.G1（2024-10-23））

> 新 SSD（Lexar NM1090 PRO 2TB）到货安装当天照着做。
> 现状：Ryzen 7 8700G（Phoenix，仅 PCIe 4.0）+ 32GB 单条 Corsair CMK5X32G2B60C40A2（标称 6000，现跑 4800）
> 更新：2026-10-21

---

## 一、物理安装（断电操作）

1. 关机 → 拔电源线 → 按一下机箱电源键放电 10 秒
2. 新盘插 **M2_2 或 M2_3**（芯片组 PCIe 4.0 ×4，独立通道）
   - **不要插 M2_4**：它和 PCI_E4 共享带宽，插上会让 PCI_E4 降到 ×2
   - **M2_1 留给系统盘**，别动，避免影响引导顺序
3. 用**主板自带的 M.2 散热片**，不要把硬盘自带散热片叠上去（会顶变形 + 影响风道）
4. 装回侧板，插电开机

---

## 二、进 BIOS

开机后**连续按 Del**（不是 F2），进入 MSI Click BIOS。

---

## 三、逐项设置

### 1. 确认新盘被识别
Settings → Storage（或主界面 Storage 页）
→ 应看到新的 NVMe（Lexar / NM1090 PRO，约 2TB）
**看不到就先别改别的**，检查是否插紧，或换到 M2_3 再试

### 2. 内存开 EXPO（4800 → 6000）
OC（Overclocking）→ A-XMP / EXPO Profile → Profile 1
- 显示应为 DDR5-6000
- 单条 32GB 跑 6000 一般稳；若开机自检失败（反复重启），改 Profile 2 或回 Auto，别硬撑

### 3. 开启虚拟化（WSL2 必需）
Settings → Advanced → CPU Configuration → SVM Mode = Enabled
- **必须开**，否则 WSL2 / 虚拟机起不来

### 4. Above 4G Decoding + Re-Size BAR
Settings → Advanced → PCI Subsystem Settings
- Above 4G Decoding = Enabled
- Re-Size BAR Support = Enabled
- 作用：一次映射大地址空间，对 780M 核显和 NVMe 吞吐都有正收益

### 5. 关闭 PCIe 省电（降延迟）
Settings → Advanced → Power Management Setup
- PCIe ASPM = Disabled（若无此选项就跳过，Windows 侧已关过）
- ErP Ready = Disabled（保持关机 USB 供电，避免外设掉线）

### 6. 风扇曲线（降噪）
Hardware Monitor
- CPU Fan：55℃ 以下 40%，70℃ 60%，85℃ 100%
- 机箱风扇同理，画平滑上升曲线，别设阶梯跳变

### 7. 启动顺序（不动）
Settings → Boot
- Boot Option #1 保持原系统盘
- **不用改 Secure Boot**，保持现状
- 新盘只做数据盘，不需要出现在启动顺序里

### 8. 保存
F10 → Yes

---

## 四、进 Windows 后初始化新盘

1. Win + X → 磁盘管理
2. 提示“初始化磁盘” → 选 **GPT**
3. 右键未分配空间 → 新建简单卷 → 盘符建议 **X:**
4. 文件系统 **NTFS**，分配单元 **4096 字节**（4K 簇）
5. 卷标可写 WSL 或 DATA

---

## 五、验证（建议做）

- CrystalDiskMark 跑顺序读写：PCIe 4.0 ×4 理论上限约 7000MB/s，实测 6000–6800 正常
- 只有 3000 左右 → 多半插在 M2_4 或走了别的通道，回 BIOS 的 Storage 页核对

---

## 六、注意事项

- ⚠️ **当前 BIOS 1.G1（2024-10-23）**，够用；非必要不升级。装完 EXPO 若不稳，再考虑升 BIOS；无事别动，升级有风险
- ⚠️ 改完开不了机：断电 → 清 CMOS（主板电池旁跳线短接 10 秒）→ 恢复默认
- ⚠️ 内存只有一条（DIMMA2），**单通道带宽只有一半**；不加内存的话高频档收益有限
- 📌 WSL 迁移（把 ext4.vhdx 移到新盘）是**另一套步骤**，到时候我另给一份，别在 BIOS 里一起干
