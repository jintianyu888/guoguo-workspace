## 根因
1. **直接原因**：长任务守卫对"停机类任务"也自动补跑，`wsl --export` 终止发行版 → 全栈中断（两次）。
2. **放大原因**：发行版重启后网关起不来，因为 state DB 里残留旧的网关所有权锁，新进程在**不同 PID namespace** 无法验证归属，报 GatewayLockNamespaceError 而拒绝启动——**这次卡了 50 分钟**（今天 09:10 那次同一根因卡了 43 分钟）。
3. **观测损失**：journal 只有 1.3G 上限且被判定损坏重建，14:24 前证据全丢；本次是靠 dmesg + 脚本日志 + cron 状态拼回来的。
