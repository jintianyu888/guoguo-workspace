## 四、长任务保完成（主公 2026-11-21 令 · 硬性）
**优先级：长任务 > 短任务。备份未完成，下游哈希/镜像/保留全部失去意义。**

机制：`tools/longtask-guard.py` + `oc-longtask-guard.timer`（每 20 分钟，零 token）
1. **判据**：长任务 = 平均 ≥600s；异常 = 从未运行 / 最近一次 error|timeout / 排程超期未触发。
2. **环境打断**（Gateway stopping、重启、owner 不在）不算失败，标记「待补」。
3. **补跑**：在夜间窗 00:30–07:30 立即补跑，每任务每天最多 2 次；**白天一律不拉重活**，进 `state/work/longtask-queue.json` 等窗内第一顺位补。
4. **依赖挂起**：全量备份失败 → 哈希/镜像/保留/周末备份自动挂起，只推一条，不刷屏。
5. **兜底**：补 2 次仍不成 → P0 推送带原因，交人处理；全过程写 `state/work/longtask-failures.jsonl`。
6. **不许静默**：任何长任务当天没完成，20:30 简报必须点名。
