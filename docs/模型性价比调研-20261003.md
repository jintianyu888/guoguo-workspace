## 一、结论摘要（≤12 行）

1. **没有「比 DeepSeek 更合适」的国外大模型**；维持现状（DeepSeek 主力 + 本地 Ollama 兜底）是最优解。
2. DeepSeek 的杀招是**缓存命中输入价**：flash 仅 **$0.003/1M**、pro **$0.022/1M**，加上闲时半价——国外一线模型缓存价普遍贵 **10–100 倍**。
3. 输出价同样碾压：DeepSeek pro 闲时 **$1.98**、flash **$0.6**；对标 Claude Sonnet 5.5 **$10**、Opus 5.5 **$20**、Gemini 3.1 Pro **$12**。
4. 最接近的国外「便宜档」：Gemini 3.1 Flash-Lite（$0.25/$2.5）、OpenAI gpt-5-nano（$0.05/$0.4）、gpt-oss-120b（$0.037/$0.17）——**单价接近或更低，但能力档位低、且中文/工具/长会话未验证优于 DeepSeek**。
5. 典型多轮长会话（10 万输入、8 成命中缓存 + 2 万输出）估算：DeepSeek pro 闲时 ≈ **$0.055**，Claude Sonnet 5.5 ≈ **$0.256**，Gemini 3.1 Pro ≈ **$0.296** —— DeepSeek 便宜约 **5 倍**。
6. 国外模型相对优势在**能力/生态**（多模态、特定工具调用、长上下文），**不在价格**；若为「更省钱」而换，是反向的。
7. 加上要过代理（延迟、稳定性、合规），换来的是更高成本 + 更低确定性。
8. 结论：**省钱场景无必要接国外**；仅当出现「DeepSeek/本地都做不了」的明确能力缺口时，再按需接入国外，且优先低成本档。
9. OpenAI / Anthropic / Google 官方价格页经代理被 **TLS 拦截**（OpenAI 另有 Cloudflare 403），证据以 OpenRouter 汇总页为主、官方页能取到就取到，均已标注来源。
10. 所有价格随行情可能变；DeepSeek 页面本身就提示「价格可能调整，请以页面为准」。

## 三、按「我们的实际用法」评估

我们的画像：**中文为主 · 多轮长会话 · 工具调用 · 长上下文 · 偶尔重活**；默认走 DeepSeek（`deepseek-v4-pro` 主力 / `deepseek-flash` 廉价档），本地 Ollama 兜底。逐项对比：

1. **中文为主**
   - DeepSeek 中文原生强、单价低；国外模型中文需额外 prompt/更多 token，隐性成本上升。
   - 结论：DeepSeek 占优。

2. **多轮长会话（缓存命中是关键）**
   - 长会话输入会大量命中缓存。DeepSeek flash 缓存命中 **$0.003/1M**、pro **$0.022/1M**。
   - Claude 缓存读 $0.10–$0.20、Gemini $0.03–$0.20、OpenAI gpt-5 缓存读 $0.125——**比 DeepSeek 高 1.4–60 倍**。
   - 结论：会话越长，DeepSeek 优势越大。

3. **工具调用**
   - 两边都支持；DeepSeek 官方页明确 ✓ Tool Calls、✓ Anthropic API 兼容。国外（Anthropic/OpenAI）工具生态更成熟，但**是能力不是省钱**。
   - 结论：省钱维度无差异；能力强需求时才考虑国外。

4. **长上下文（1M）**
   - DeepSeek flash/pro、Qwen 3.8、GLM 5.3、Kimi K3、Gemini 3.x 都有 1M。
   - 但 1M+长会话场景下，缓存差价被放大，DeepSeek 更省。
   - 结论：DeepSeek 够用且更省。

5. **偶尔重活（高质量推理）**
   - DeepSeek 可临时升级；若真要国外「聪明档」：Claude Opus 5.5 $4/$20、Gemini 3.1 Pro $2/$12、OpenAI gpt-5.2-pro $21/$168——**全部远贵于 DeepSeek pro 闲时 $0.66/$1.98**。
   - 结论：重活也不划算，除非有明确能力缺口。

**典型成本估算（10 万输入、80% 命中缓存、2 万输出）**

| 方案 | 估算成本 | 相对 DeepSeek |
|---|---|---|
| DeepSeek v4-pro（闲时） | ≈ $0.055 | 1× |
| DeepSeek v4-pro（峰值） | ≈ $0.11 | 2× |
| Claude Sonnet 5.5 | ≈ $0.256 | ≈ 4.7× |
| Gemini 3.1 Pro | ≈ $0.296 | ≈ 5.4× |
