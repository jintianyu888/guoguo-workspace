## 使用规则

1. 顶上顺序不变：默认链 deepseek-flash → zai/glm-5.3-flash → zai/glm-5.3 → kimi-for-coding → deepseek-v4-pro → ollama/qwen3:30b。接替表是「每家一张牌」的索引，不改变链序。
2. 某厂商整条线不可用时，按链序跳到下一家；同厂商内部优先用表内接替牌，不现挑现测。
3. 评审池（旗舰档）与接替表（flash 档）相互独立：接替牌允许 flash/廉价档，评审池仍禁。

## 准入与审核

- **新厂商接入**：必须先过 `python3 tools/model-eval.py <provider/model> quick` 两题全 PASS 才准入表；评测记录入 docs/模型评测台账.md。
- **每周五周审**：核一遍本表（模型下线 / 涨价 / 新旗舰发布 → 更新并重测），结论记入本文末尾变更记录。
- **每日 03:00 model-watch 自动巡检只告警不换表**（2026-10-30 双审修正，防频繁换牌）：发现候选新模型只飞书通报并跑准入评测留档；换表必须同时满足：①准入两题 PASS ②相比现接替牌有量化优势（速度/成本/质量至少一项明显更优）③周五周审复核确认，才换并报备。
- 同一厂商的接替牌更换不触发双审（模型经济性自授权范围）；但 **默认链顺序变更** 必须双审。
