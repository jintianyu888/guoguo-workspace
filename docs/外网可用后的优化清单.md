# 外网可用后的优化清单（2026-10-03）

> 背景：2026-10-03 打通 Windows 代理（WSL 侧入口 `http://172.18.240.1:7890`，出口 IP 香港）。主公令：**代理常开、直接拿来用**，分析能优化什么并落地。

## 0. 实测基线（2026-10-03 15:xx）
| 目标 | 结果 |
|---|---|
| github.com | 200 · 0.43s |

## 1. 立刻可用（已落地/待落地）
1. **依赖与源码下载提速**：GitHub / raw.githubusercontent / PyPI / npm / HuggingFace 直连。以前靠国内镜像，现在走代理又快又全。
   - 工具：`tools/with-proxy.sh <命令>`（只给该命令加代理）
   - 例：`tools/with-proxy.sh curl -sSL -O https://github.com/.../x.tar.gz`
   - 待落地：`tools/dl-fast.sh` 增加「外网直连」开关（走代理 + 8 线并发）
2. **模型下载**：HuggingFace 模型（ASR/OCR/embedding/rerank/新模型）可直接拉；`whisper-wrapper.py` 里的 `HF_ENDPOINT=hf-mirror` 可考虑改回官方（代理下更快/更全）。
3. **新闻/资讯**：国外源（BBC/DW/NYT/NHK 等）已通知 news 管家纳入；只给国外请求加代理。
4. **研究查资料**：Google / Stack Overflow / 官方文档 可直接访问，疑难排查效率提升。

## 2. 需主公拍板（花钱/对外）
- 国外模型 API（Claude/GPT/Gemini）等：代码改动 + 按量付费 → 需主公同意后再做。

## 3. 安全边界（铁律）
- 代理**只用于公开网页抓取 / 国外下载 / 研究**；
- **密钥 / 飞书 / 群晖 / 国内服务一律不走代理**（避免延迟、避免凭据经过第三方节点）。
- 代理入口变化时只需改 `tools/with-proxy.sh` 一处。
