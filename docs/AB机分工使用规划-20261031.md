## 一、一句话分工

## 二、A 机职责（3070 8G）
1. 网关 + 21 个管家的运行环境（现状不变）。
2. GPU 专用小任务（单发、短时）：whisper ASR（比 CPU 快 2.7 倍）、人脸识别 insightface（64ms/张 vs CPU 156ms）、OCR、MusicGen（fp16，medium 档）。
3. 硬约束：8G 显存同时只允许 1 个 GPU 任务，musicgen/whisper/face 必须串行（flock），谁抢显存就直接失败。
4. 不装本地 LLM：local 别名走 ollama-proxy，实际在 B 机上跑，A 机零显存占用。
