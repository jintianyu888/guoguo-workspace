## 三、对齐规则

1. 同一时段的管家任务间隔 ≥10 分钟，避免同时抢模型与磁盘 IO。
2. 所有自审必须在 12:55 前跑完，13:00 汇总才能拿到完整结果。
3. 报告类投递一律 announce → 飞书 user:ou_74fec7bc81cc6ec6d2b4de1c0967923b；不再用 delivery=none（等于自言自语）。
4. 每项任务超时统一 900s，超时即算失败，由 13:00 汇总结算。
5. 果果 13:00 汇总同时核对四家当日任务 lastRunStatus，error 的一并列出并当天修。
