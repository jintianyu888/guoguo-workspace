## 四、命名规范（以后新增一律照此）

- 主用 key 保持 厂商_API_KEY（provider 默认按约定读取，不要改）
- 其余一律带账号标签：_OFFICIAL / _7FOLD / _BACKUP / _日期
- 入库后立刻在本表登记一行

## 五、改名的硬限制（重要）

- 密钥仓**只写**：读不出 secret 值；CLI **没有 rename/mv**
- 所以「改名」= 用加密框**重新录入一次**新名字的值（旧的软删除）
- 不改名也完全没问题：靠本表 + 命名规范就不会混（推荐）
