# 管家记分规则（2026-11-07 主公令）

适用范围：果果(main)、维护(maint)、备份(backup)、模型(model)、干活(work)、Hermess(sheet-music)、格格(print)、资讯(news)。
所有分数只来自落盘数据（台账 state/tasks/tasks.db、cron 回执 state/openclaw.sqlite、各家自审文件、人工调整 JSON），不靠自评嘴说。

## 一、单任务分（每人每天）
基准 10 分/条，按完成时刻与 due_plan 差值：
- 提前 ≥24h：+5
- 提前 ≥2h：+3
- 提前 ≥15min：+1
- 准时（±15min）：0
- 逾期 ≤2h：−2
- 逾期 ≤24h：−5
- 逾期 >24h：−10，并标 STALE
- 逾期仍未完成：写了原因 0 分；没写 −5

## 二、管家周记分（每人每周，基准 100）
- 任务：本周 due_plan 落在周期内的台账项，按上表累加，封顶 +40、下限 −30
- cron：本周 cron 回执成功率，扣分 =（1−成功率）×20
- 自审：应每天一份（果果/维护/备份/模型/干活/Hermess），缺一天 −2；格格与资讯不考核自审
- 人工：state/plan/adjustments-YYYYMMDD.json 中带 agent 字段的加扣项（返工、事故、虚报）

## 三、硬性附则
- 交付即出故障（返工）每次 −5，修补本身不加分
- 报错数据（口径错、字数错、假绿）每处 −3
- 只有带验收证据（rc、实测输出、文件路径）才算完成
- 扣分项只能由主公删除，助理不得自删自改
- 每周日 21:35 由「周计划与记分榜」任务生成并推送周报：state/plan/butler-score-<年>-W<周>.md

脚本：tools/plan-score.py（单人日分）、tools/butler-score.py（全家周分）。
