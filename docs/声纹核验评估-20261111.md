# 声纹核验基线评估（2026-11-11）

## 结论
用主公历史语音自建模板可行，同人/异人分离度很大，可作**辅助判据**，不能单独当钥匙（录音重放仍可绕过）。

## 方法
- 模型：speechbrain 1.1.2 + ECAPA-TDNN（speechbrain/spkrec-ecapa-voxceleb），本地 GPU
- 语料：\`/home/j/.openclaw/media/inbound/*.ogg\` 共 340 段（主公飞书语音），16k 单声道经 ffmpeg 转码
- 注册集：最长的 8 段 → 均值模板 \`state/voiceprint/zhugong.npz\`
- 测试：其余 340 段全部打分（长度分层统计）
- 负样本：3 段公开真人语音（英语男声，hf-mirror 下载）

## 同人分数（按音频时长分层，余弦相似度）
- <3 秒：n=15，中位 0.593，最低 0.021（短音频不可靠）
- 3–5 秒：n=19，中位 0.691，最低 0.201
- 5–10 秒：n=88，中位 0.743，最低 0.513
- 10–30 秒：n=158，中位 0.825，最低 0.609
- >30 秒：n=60，中位 0.888，最低 0.710

## 负样本（真人异人，20 秒）
- -0.0031 / -0.0098 / 0.0804

## 建议阈值（要求音频 ≥5 秒）
- ≥0.50：通过
- 0.30–0.50：存疑，要求二次确认
- <0.30：拒绝
- 分离边界：同人最低 0.513 vs 异人最高 0.080，间隔 0.43

## 已知局限（务必写进使用规则）
1. **录音重放可绕过**：播放主公的语音片段同样能拿到高分。这只是"声音像不像"，不是"人是不是在场"。
2. 负样本只有 3 段英语男声，FAR 只是下限估计，中文异人/近亲声音需要补测。
3. 短音频（<3 秒）已从核验中排除，工具直接报 too short。
4. 情绪激动/耳语/戴口罩会掉分，掉分不等于冒充，故设"存疑"档而非直接拒绝。
5. 硬边界不变：钱、权限、删除、外发四类仍要显式确认，不看声纹分数。
