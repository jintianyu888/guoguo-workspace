> 主公 2026-10-04 15:21 令：闲时、无任务时，以最少/零 token 给所有项目方方面面做体检，形成自查方案，时刻发现问题、解决问题、排除潜在风险。
> 与《监控清单》（2026-09-29 令）同源，本方案是它的「调度层 + 闲时轮转层」。

## 0. 原则（铁律）
1. **零 token 优先**：能用 `command` 类定时任务/纯脚本做完的，绝不唤起模型。
2. **干净即静默**：一切正常 → 不说话；只在异常时开口。
3. **闲时做重活**：需要模型/大算力的，排 DeepSeek 闲时（半价，北京 12:00–14:00、18:00–09:00、整周末、节假日）或本地模型。
4. **不隐藏**：任何「卡住/未完成/降级」都必须可见（页脚/台账）。
5. **不重复报**：同一问题「发现时 + 解决时」各报一次，之后翻篇。
6. **能自愈就自愈**：重启/回落/重试/补齐；不能自愈的带方案报主公。

## 1. 四层节奏（频率阶梯）
### L0 心跳层（每 5–20 分钟 · 0 token · 纯脚本）
- 模型可用性探针（frequent-checks-5m / llm-failover）
- `health-alert.sh` 备份·安全告警（每 20 分钟）
- `proc-watch.sh` 僵尸/不可中断(D)进程/挂死 ssh·rsync·tar
- `tmp-watch.sh` /tmp ≥80%/92%
- `dl-watchdog.sh` 下载卡住自动重启（>10 分钟无增长）
- 网关内存自愈（heap/swap 阈值→压缩/重启）

### L1 小时层（每 1 小时 · 0 token）
- `project-monitor.py` 全项目哨兵（备份/网关/渠道/凭据/任务失败/磁盘）
- `inbox-check.py` 工作区收件箱
- `tasks.sh check` 待办自检（重复 ID/过期/残留）
- automations 失败/超期 扫描

### L2 每日闲时层（0 token 脚本；仅异常才叫模型）
- 04:40 `audit-scripts.py` 脚本语法/冲突/红线/漂移
- 07:20 `project-monitor.py` 全量巡检
- 「每日系统自检」
- `backup-report.sh` 备份快报 + `backup-drill.sh` 恢复演练
- `asset-audit.py` 资产清单比对

### L3 每周闲时层（半价时段）
- 深度体检轮转（见 §3），每周跑 1–2 项
- 周报（含各管家用量明细：tokens/花费/缓存/次数）

### L4 每月闲时层
- 全量灾备演练（解包抽取关键文件）
- GPU/流程三方案复测（1 日 22:00）
- 资产安全审查 + 能力矩阵 + 供应商/密钥轮换检查 + 月报

## 2. 覆盖维度（12 类「方方面面」）
1. **资源/主机**：CPU·内存·swap·/tmp·磁盘·GPU·进程（僵尸/挂死）
2. **网关**：PID·RSS·端口·崩溃重启·日志错误
3. **备份**：四层（①每4h数据库 git ②每4h工作区 git ③.ssh 加密 ④每日全量）+ 保留策略 + 异地一致性 + 恢复演练
4. **定时任务**：enabled·失败·超期·时段经济性·重复
5. **项目哨兵**：每个项目的状态文件 + 阈值 + 自愈
6. **渠道/管家**：飞书·wecom·节点连接·凭据在位·路由
7. **安全**：密钥泄露·越权·公网入口·异常登录·权限放宽·可疑进程
8. **脚本与资产**：语法·漂移·重复写目标·失效路径·来源可信
9. **成本**：token·模型档次·缓存命中·闲时排期·余额
10. **记忆与文档**：索引·矛盾条目·过期待办·归档完整性
11. **数据完整性**：SQLite·索引·回收站清单·字节校验
12. **依赖与版本**：包·CUDA·模型·GPU 驱动

## 3. 闲时「深度体检轮转」（核心增量）
- 队列文件：`state/selfcheck-queue.json`，登记「需深度检查但不紧急」的项（项目全链路/渠道联通/脚本依赖/密钥轮换/记忆一致性…）。
- 触发：**无任务 + 处于闲时** → 每次取 1 项，跑对应 0-token 脚本。
  - 正常 → 记一行，出队/顺延，静默。
  - 有问题 → 能自愈自愈；不能 → 按性质选最便宜档派子任务处理 + 报备。
- 调度器：`tools/selfcheck.py`（0 token）统一跑、汇总 `state/selfcheck-report.json`；干净→静默。
- 目标：一周内把所有项目轮一遍。

## 4. 告警规则
- 干净 → 静默（不刷主公）。
- 🔴 急（备份/安全/网关挂/磁盘满）→ 立刻 + 多次，最高优先，压过省时段。
- ⚠️ 留意 → 汇总进日报/周报。
- 每条异常三段：①是什么 ②要不要紧 ③我建议这么做 + 我已做。

## 5. Token 账
- L0–L2：**0 token**（command 定时任务 + 本地脚本）。
- 只有「发现真问题」才唤起模型一次，按性质选档（机械→flash，复杂→v4-pro/smart，私密→本地）。
- L3/L4 深度项排闲时（半价）。
