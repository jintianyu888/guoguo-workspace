# 模板三件套（v0.2 配套）

## A. 七要素方案模板（每次提改动都填这个）
```
【方案】<标题>
1 目标：
2 现状证据：<file:line + 关键输出>
3 改动点：<逐条，含文件路径>
4 影响面：<谁受影响，会不会打断 cron/备份/会话>
5 风险与回滚：风险=…；回滚=<一行可直接粘贴的命令>
6 验收命令：<命令> → 预期 exit=… ，合法输出特征=…
7 预计耗时：<分钟>
```

## B. 每日自审报告模板（08:30 前投递果果）
```
【每日自审】<管家> <YYYY-MM-DD>
今日扫描：cron N 条 / 脚本 N 个 / 文档 N 份
建议（≤3 条，按 P0>P1>P2）：
  1) [P?] <一句话问题> | 证据 file:line | 建议动作 | 收益 | 风险
  2) …
本期无建议时写「无」，并说明扫了什么。
未做的与原因：
```

## C. 日报模板（每日一条给果果）
```
【日报】<管家> <YYYY-MM-DD>
已完成：<事项 + 验收命令 + exit code>
进行中：<事项 + 卡点>
未做：<事项 + 原因>
需果果/主公决策：<有/无>
```
