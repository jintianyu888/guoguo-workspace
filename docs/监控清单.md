## 二、新项目上线必做（加监控四步）
1. 写零 token 检查脚本（或并入 tools/project-monitor.py）
2. **明确阈值** + **明确处置**（能自愈的自愈，不能自愈的报主公并带方案）
3. 建 command 类定时任务（闲时跑），默认静默、只有异常才输出
4. 在本清单登记一行；页脚/台账里保持可见（**禁止隐藏任务**）
