# B 机接入为 OpenClaw 节点 — 方案与决策（2026-10-30）

## 一、结论（已定，甲 + 甲）

| 项 | 选择 | 理由 |
|---|---|---|
| 权限账户 | **普通用户**（不要管理员） | 系统级操作被 UAC 拦住，最坏情况可恢复；节点服务不需要提权 |
| 版本策略 | **节点与网关同版本**（当前 2026.10.8 / dc2523e） | 官方文档：新能力要求"compatible builds"；不同步=能连但新功能缺失或语义错位 |

## 三、权限边界（明示）

能做：任意命令（system.run）、读写文件、启停服务（同用户权限内）、用 B 的 GPU
不能做：管理员级操作（UAC 拦）、其他用户数据、图形界面点击、关机/BIOS、其他机器

命令白名单：system.run, system.which, node.describe

## 五、跟升规则（写进升级流程）

A 机升级网关后，同一窗口内把 B 节点升到同版本：
```
npx -y openclaw@<新版本> connect <新配对码> --service --commands system.run,system.which,node.describe
```

## 六、撤销

A 侧：移除设备表条目（openclaw devices remove）
B 侧：npx -y openclaw@2026.10.8 node stop
