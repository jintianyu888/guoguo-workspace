# 管家权限分级方案 v1.0（2026-11-16 主公批准）

## 0. 一句话
从「默认全禁、只读」改为「分层放权 + 强制可回退」，先给 维护(maint) 与 备份(backup) 试点两周。

## 1. 三层权限

### L1（所有管家，已有）
- 只读工具：exec 读取类命令、读文件、查询接口
- 自己的 workspace 写入（workspace-<agent>）
- 零 token 脚本（不调模型的脚本）

### L2（本次开放，按管家限定）
| 管家 | 新增能力 | 明确不许 |
|---|---|---|
| maint | systemctl --user status/list-timers；**重启自己名下的 timer**；跑 tools/ 下修复脚本；写 state/maint-alerts/ | 重启网关、安全类服务、改系统级 unit |
| backup | 保留策略清理（工具入口，两阶段：隔离→到期删）；跑恢复演练；写 backups.db | 跨盘删除、绕开隔离区直接 rm、删唯一副本 |
| model | 改沙箱内路由配置（改完必须 --dry-run 验证）；探活 provider | 改主配置、改密钥、动 fallback 链以外的文件 |
| work | 跑 tools/ 脚本；自己 workspace 内移动文件；提交自己分支 | 跨 workspace 移动、动别人账本 |
| hermess | 读写自己 docs；走 tools/notify.sh 批准的通道发报告 | 直接调飞书 API 群发、发外部消息 |

### L3（永不放开，走主公或果果）
删除（除回收站/隔离流程）、密钥、权限扩容、花钱、对外发消息、网关重启、跨机删除、改 agent 权限本身

## 2. 五条护栏（硬性，缺一不放开）
1. **入账**：每个 L2 动作必须调 `python3 tools/exec-ledger.py add` 记 完成时间/是否完成/复用/优化/证据/回滚
2. **两阶段**：破坏性动作 dry-run → 隔离区 → 到期清理，禁止一步删
3. **冻结开关**：存在 `state/work/butlers-frozen` 时所有 L2 立即停（`tools/l2-run.sh` 自动拦截）
4. **抽样审查**：每周抽 20% L2 动作复核；同一管家违规 ≥3 次收回 L2
5. **执行包装**：L2 命令统一走 `tools/l2-run.sh <butler> "<命令>"`，自动记录 + 冻结检查

## 3. 试点
- 期：2 周（2026-11-16 → 11-30）
- 对象：maint、backup
- 通过标准：无越界动作、L2 动作 100% 有账、至少完成 3 件此前被挡住的事
- 通过后：model / work / hermess 依次放开，每次隔一周

## 4. 回滚
- 单管家：把该 agent 的 exec.safeBins 还原为上一版（快照 state/work/agent-exec-snapshot-20261116.json）
- 全局：`touch state/work/butlers-frozen`
