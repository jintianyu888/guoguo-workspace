# 跨设备/跨网络文件互传 与 VPN 现状（2026-11-15 实测）

## 一、实测结论（A 机 GY）
- Tailscale 在跑：节点 GY，Tailscale IP 100.109.128.37，tailnet 域名 gy.taild2d30d.ts.net
- tailscale serve 只代理了 / → 127.0.0.1:18789（tailnet only，不是公网）
- 本机**没有任何翻墙代理**：7890/7891/1080/10808/10809/2080 全未监听；WSL 出网 baidu 200 / google 不通
- Windows 侧端口转发（netsh portproxy → WSL 172.18.242.44）：18789 / 9443 / 8899 / 18899；18888 需管理员加（已写入桌面 WSL重启后修复.bat 第 14 行）
- 手机 USB adb 可用：设备 3B6F64E8GCL1FBZ0（PLC110），走 Windows 版 adb.exe /home/j/.local/opt/platform-tools/adb.exe，封装在 tools/adb.sh
- 手机走 VPN 时 2.x 网段可达但 PMTU≈800-1000、延迟 100-300ms（隧道特征）；打印机 2.54 是 3.2ms 真局域网

## 二、大文件互传的四条可用路（无 30M 限制）
1. NAS 中转：//192.168.1.109/home 已挂 /mnt/nas（rw，SMB3），写速约 31MB/s
2. 自建 HTTP 文件站：tools/share.sh start（18888，带 token，支持 GET + PUT 流式上传，实测 40MB/60MB 通过）
3. 手机 USB：bash tools/adb.sh push/pull（无限制，最快）
4. 局域网 SMB 直连 B/C 机共享

## 三、异地（不在同一局域网）怎么办
- 装客户端方案：Tailscale（iOS/Android/Windows/macOS/Linux 官方客户端；鸿蒙 NEXT 无客户端，鸿蒙 4 可装安卓 APK）
- 不装方案：公网中转服务（阿里云盘/夸克/文叔叔/WeTransfer）或飞书云文档
- 自建公网方案：tailscale funnel（需先让 WSL 端口在 Windows 侧可访问；且只应暴露文件站，不暴露面板）

## 四、node file.write 不可用（已排除）
- openclaw nodes list --json：三节点上报命令只有 fs.listDir / terminal.upload / system.run / system.which 等，**无 file.read / file.write**
- file-transfer 插件自述：经 node.invoke 传二进制上限 16MB
→ 结论：开通授权也没用，节点不实现该命令且容量不足
