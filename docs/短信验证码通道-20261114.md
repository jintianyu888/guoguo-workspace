## 坑
- WSL IP 会漂（当前 172.18.242.44），重启 WSL 后需重跑 /mnt/c/Users/Public/开启短信接收端口.bat 刷新 portproxy
- 一加 USB 安装被系统拦（Failure -99），需开发者选项「USB 安装」或手动装
- pm grant 被 ColorOS 拒（无 GRANT_RUNTIME_PERMISSIONS），权限必须 UI 点
- adb reverse tcp:18899 只能临时用（插线时），不能作为长期通道
