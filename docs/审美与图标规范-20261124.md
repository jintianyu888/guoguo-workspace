# 审美提升与图标规范 — 2026-11-24

主公问：有没有方法可以提高你的审美。答：审美不能靠"多看图"自觉，得变成可判定的检查项 + 参考集 + 迭代闭环。已经落地三件事。

## 一、把审美拆成机器能判的指标（tools/icon-review.py）
- 32px 可读性：缩小到 32×32 后的亮度对比 ≥0.55、白色主体占比 ≥0.12（低于此在消息列表里就是一团色块）
- 锐度：拉普拉斯边缘均值 ≥15，糊掉的立体阴影会被判低
- 区分度：与现有 39 个图标的色相最近邻距离，<18° 时提示"色相接近但图形不同"，提醒换形状而不是换色
- 一致性：背景对角渐变、单一橙色点缀（#FF9A2E/#FFD9A8）、主体白/浅蓝白
- 用法：出图即跑，GREEN 才上传；WARN 必须改完再传

## 二、参考集与规则（审美判断的锚点）
- 主体只能有一个：一句话说得清"这是什么"（胶片=剪辑、龙门架=3D打印、天秤=法律）
- 剪影优先：去掉颜色只剩黑白轮廓时仍可辨认
- 不做字：图标里不写中文/英文单词（首字徽章只在没有语义图形时兜底）
- 同系列不同形：同一族（健康×4、公司×3）必须形状可区分，不能只换颜色或数字
- 反例库：白方块（原剪辑）、显示器造型（原 3D 打印）、浅粉发白皇冠（原格格）——都记在 docs 里，下次不重犯

## 三、迭代闭环
1. 生成：tools/icon-forge.py（SVG 源码，参数化颜色/图形）
2. 自检：tools/icon-review.py（机器指标）+ 自己看 240px/32px 双尺寸拼图（view_image）
3. 他证：拿不准的交给双顾问（qwen 找更优、glm 找风险），或让异厂商模型复评
4. 上线：tools/icon-apply.js（上传+建版本+发布）→ tools/icon-verify.py（线上 vs 本地 mad<18）
5. 复评：每个季度随管家新增一起过一遍全部图标；同一图标被主公点名 2 次直接重做

## 四、新管家自动出头像（R40）
- 规则：新管家上线当轮必须生成并发布头像，未做 = 红（每日闸门 R40 检查）
- 一条命令：bash tools/new-butler-icon.sh <appId> "<中文名>" <领域关键词>
  - 命中领域词 → 复用库内对应设计；未命中 → 自动生成首字徽章（渐变+白圆+领域色）
  - 自动渲染 480×480 → 上传 → 建版本 → 发布 → 写 state/icons/registry.json
- 验收：bash tools/r40-new-butler-icon.sh（39/39 覆盖，缺记录即红）
- 相关：state/icons/registry.json 是头像唯一台账（appId → 名称/图/时间）
