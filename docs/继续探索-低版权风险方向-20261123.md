# 继续探索：零/低版权风险的可做方向（2026-11-23）

> 起因：公版乐谱方向被否——需求主力是流行曲（侵权区），合法区（公版古典）需求薄。
> 原则：只选**客户自带素材**或**我方完全自有**的方向，版权风险≈0。

## 一、候选方向与实测数据

### 1. 老照片修复（需求最硬）
- 淘宝：50 元/张为显性标价，头部链接已售 1 万+；有店铺月销 4000+（单价 50 元口径），单店月营收 20 万+；另有头部店月销 8500+ 单，按 50 元算月营收约 42.5 万。
- 客单价：淘宝店平均 60–120 元/单；某店年经手约 15 万张、年营业额近 1000 万。
- 闲鱼个人：基础 8–12 元，精修 25–40 元，遗照 50–80 元（按人头加价）；有卖家三个月 200+ 单、均价 18 元、净收入近 4000 元。
- 小红书：9.9 元引流 → 39–199 元成交，私域客单更高。
- 版权风险：**零**（客户自己的照片）。隐私是唯一红线（人像数据本地处理、不外传）。
- 竞争：极卷，AI 工具把基础档打成白菜价 → 只能靠“遗照/多人物/严重破损/24 小时交付/隐私承诺”吃溢价。

### 2. 机构数字化/自动化代搭（客单高，但客户没钱）
- 行业基本面（2025 成都美育白皮书 + 行业汇总）：续费率 65–75%(2019) → **30–40%(2025)**；获客成本 100–200 → **300–1000 元/人**；毛利率 45–55% → **5–15%**；2025 年少儿艺术机构注销 3.8 万家（+27%）。
- SaaS 价格天花板：499 元/年（小禾帮）、599/1288（学蝉）、1598/1998/2688（艺小粒）、7050 起（德尔普）。
- 结论：**别卖 SaaS**（红海+客户付不起）。卖“一次性交付省钱工具 + 低年费维护”：排课/消课提醒、家长周报自动生成、考级材料批量排版、招生内容批量产出。
- 版权风险：零（自研工具/客户数据）。
- 你的优势：自己就是机构主，需求真实、能自证效果、有同行样本。

### 3. 3D 打印代打/定制（价格透明，靠本地急件）
- 材料计价：PLA 散单 0.1–1.6 元/克，批量 0.17–0.26；PETG 0.09–1.5；TPU 0.29–0.4。
- 按件：钥匙扣 8–15 元；手机支架/收纳 25–45 元；中小摆件/手办 60–110 元。
- 含建模的修复件：建模费 30–120 元，简单卡扣 30–50 元，复杂曲面 80–120 元；本地急用件（家电旋钮等）成交 80–150 元。
- 结构性问题：纯代打被按克压价，利润靠“建模 + 本地当天 + 小批量”。
- 版权风险：低，但**不能打他人 IP 手办**（LABUBU 这类是侵权高发区）。

### 4. 短视频剪辑/音频修复代做（未采集到可靠报价）
- 检索未拿到可信的价格与销量数字，**标未采集**，不据此排序。
- 已知结构性事实：客户自带素材 → 版权风险低；竞争极卷，价格锚点低。

## 二、排序（按“需求已验证 × 起量速度 × 你的资产匹配”）
1. **老照片修复**：需求最硬、当天能接单、零版权。天花板低但现金流快。
2. **机构自动化代搭**：客单高（可 1000–5000/次），但成交周期长、客户预算紧。适合做“样板客户+案例”慢慢铺。
3. **3D 打印本地急件/教具**：与你的琴房场景天然咬合（教具、谱架配件、修复件），单价不高但复购稳定。
4. 剪辑/AI 代做：等有真实报价数据再评估。

## 三、推荐组合（不是单选）
- **前端引流**：老照片修复（小红书/闲鱼，9.9 引流、39–199 成交），承担现金流与获客。
- **后端利润**：机构自动化（把修复赚来的流量里筛出机构老板，卖 1000–5000 的交付）。
- **顺带变现**：3D 打印接本地急件与教具小单，填充设备闲置时间。

## 四、7 天验证动作（可机器核验）
1. 出 10 张修复样片（用自家老照片，对比图），发 3 条笔记 → 目标：≥20 个私信咨询。
2. 给 5 家同行机构发一页“免费生成家长周报”的演示 → 目标：≥2 家愿意试用。
3. 挂 3 个 3D 打印 SKU（教具/修复件/摆件）→ 目标：≥1 单成交。
判据：三项里至少两项达标才加投入；否则换切口。
