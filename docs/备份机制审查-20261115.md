# 备份管家机制审查 — 2026-11-15

> 触发：主公问「备份管家机制审查一遍，怎么回事」。证据全部来自 2026-11-15 实测与 cron/日志原文。

## 一、现在的链条（审查对象）

- 01:00 `每日全量备份归档`（timeout 3h）→ heartbeat-run → backup-with-quiet（暂停 cron 静默）→ nas-push-archive create：打包 → 复制 X → 复制 D → 推 NAS → 保留策略 → 清暂存
- 04:00 `备份镜像+校验(每日)`（timeout 2h）→ backup-mirror-verify：D→E→H rsync 镜像 + 校验 + 台账
- 06:35 `备份哈希清单` / 06:40 `T1重点备份`×2 / 07:10 `每日备份与盘位报告` / 07:30 `E/H 整机镜像一致性`
- 18:20 周二 `T2中间备份`（timeout 30min）
- 23:40 `今晚全量备份+备份审查+数据核对`（agentTurn，花 token）
- 月 1 日 `WSL整机镜像(每月E+H)`（timeout 3h）

## 二、实测耗时（11-15 日志原文）

- 01:02 开始打包 → 03:25:50 打包完成（**2h24m**，127.2G）
- 03:53:08 开始推 NAS → 04:00 任务被 3h 超时杀掉（exit 143），NAS 未推完
- 04:01 第二个 job 又打一份 → 06:21:13 打包完成（**2h20m**，127.9G）→ 06:50 开始推 NAS → 08:00 网关重启打断（Gateway stopping）
- NAS 实测写速 **31MB/s**，119G 需 **60+ 分钟**；今天两个残片 62G / 95G 就是两次被杀的产物

## 三、根因（5 条，按严重度）

1. **单任务塞满全链路，必然超时**：打包 2.4h + 复制 0.5h + NAS 推 1h+ > 3h 上限。每晚必被杀，`exit 143`，任务永久 error
2. **杀完就重来，没有去重**：被杀 → OpenClaw 重试 + 04:00 另一个 job 再打一份 → 一天两份 119–120G，把 vhdx 撑大（今天已修）
3. **NAS 推送不可续传**：`cp` 一把梭，断了从头；31MB/s 下等于每次赌博
4. **没有看门狗**：`systemctl list-timers 'backup*'` 返回 **0 个定时器**，11-07 之后备份失败全靠人肉发现
5. **超时与实耗不匹配**：T2 每周给 30 分钟（实际远超）→ 连续 4 次 error；04:00 镜像任务与 08:00 重启窗口相撞 → 被中断

## 四、今天做的修复（已落地）

1. `nas-push-archive.sh`：
   - **去重**：今日已有 <12h 且 >10G 的归档则跳过打包（仍执行落盘/推送）
   - **暂存兜底清理**：EXIT trap，超时被杀也清；只清 STAGE 且 X 有同尺寸副本
   - **NAS 推送异步化**：打包+落盘完立即 `systemd-run` 派发独立推送单元，不再占用备份窗口（`NP_ASYNC=1` 默认）
   - **推送可续传**：`cp` 改 `rsync -a --partial --inplace --append-verify`，断点接着传
   - `NP_DRY=1` 干跑开关
2. `daily-backup.sh`：入口先查重，实测 0.037s 返回
3. **超时对齐**：01:00 任务 3h → 4h；T2 每周 30min → 90min
4. **新增看门狗** `backup-watchdog.sh` + `backup-watchdog.timer`（每 30 分钟，零 token）：
   - 最新 D 归档 >30h → 告警（断档）
   - backup-stage 有 >6h 未清归档 → 告警（泄漏）
   - 10:00 后 NAS 当日无完整副本（只认非 .part）→ 告警
   - 每 2 小时查一次备份类 cron 连续报错 ≥2 → 告警
   - 首跑即抓到真问题：**NAS 当日 0 个完整副本、2 个残片**

## 五、还没解决（需要主公拍板）

1. **E/H 双份镜像**：04:00 任务把 119G 再 rsync 到 E 和 H 各一份。E 盘已 90%（剩 385G），照这个节奏一个月就满。建议：只保留 H（或 E 降为每周一次）
2. **打包 2h24m 是否值得**：`--verify` 占了不少时间；若改为「打包后只做抽样校验、全量哈希交给 06:35 独立任务」，可省约 40–60 分钟
3. **23:40 的 agentTurn 备份审查**：花 token 做的事，看门狗已能用零 token 覆盖大半，可考虑降级或合并
