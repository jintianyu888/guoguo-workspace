> **周末与节假日条款（2026-11-01 主公令，最高优先）**
> 周六、周日、中国法定节假日**全天半价**，视同半价窗：**不限工、不进待办队列、重活白天就做**。

> 判断一律以 sh tools/peak-status.sh 输出为准：RED=高峰全价，GREEN=闲时半价。**禁止自己凭日期推断。**
> 节假日名单：state/holidays.txt。

## 四、建任务前的六问（逐条回答后才能建）

1. **落在哪个窗口？** 对照第一节，撞红区/断网窗/高峰＝不合格，换时间。
2. **要联网吗？** 要联网就不能进 04:00-06:05；只读本地可以。
3. **要花模型钱吗？** 要，就不能进工作日 09-12 / 14-18；进 18:00 后或 12:00-14:00。
4. **跑多久？** 近 7 天实测耗时写进任务说明；没有实测不许建。
5. **会不会和已有任务抢资源？** 同窗口同资源（GPU/磁盘 IO/备份锁）只能有一个重活，前后留 30-50 分钟。
6. **怎么判成功？** 必须给可判定命令（看 exit code），不接受“应该成功了”。

## 五、变更流程（谁提、谁批、谁验）

- **管家**：出方案（含新时刻、理由、耗时证据、验证命令），写进自己 workspace 的 `state/work/plan-*.md`，用 `tools/agent-msg.sh send main` 回果果。
- **果果**：审核方案 → 执行 cron 改动 → 回读校验 → 更新本文档 → 报主公。管家无写权限时，执行权只在果果。
- **主公**：只批「权限扩张、重启级、批量删除、密钥」四类。改个时刻不用找主公。
- **验收**：改动后必须等它真实跑一次，看 exit code + 产出物，才算通过；不许以“配置回读正确”当验收。
