# 工作区「回收站」机制

> 建立于 2026-09-26 · 老板指定 · 经手人 main（果果）

## 一、设计

根目录 `回收站/` 统一收纳所有废弃的任务 / 文件 / 日程，**一律 move、绝不真删**，保留期 ≥ 1 年，到期默认继续留、不自动删。

目录结构：
- `回收站/README.md` —— 回收站策略（什么该进、谁批准、保留期、到期处理）
- `回收站/manifest.jsonl` —— 记账清单，每行一条 JSON（时间 / 类型 / 名称 / 来源路径 / 为什么废弃 / 经手人 / 移入路径）
- `回收站/items/YYYY-MM/` —— 实际移入的文件，按分月存放，保留原文件名

## 二、用法

```bash
# 移入文件（move，保留原名，按年月归档）
./tools/trash-add.sh <路径> --reason "..." --type file

# 记账一个任务 / 日程 / 已删除的定时任务（不搬文件）
./tools/trash-add.sh "任务名" --reason "..." --type task --source "state/pending-tasks.md"
./tools/trash-add.sh "日程名" --reason "..." --type schedule --source "schedule-report.json"

# 输出报表（供日报用）
./tools/trash-report.sh
```
