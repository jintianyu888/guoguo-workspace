# 技能自优化机制（2026-11-10 主公令）

> 主公原话：「hermes 可以记住每次正确的技能，并且不断优化这个技能，我觉得你也行。」
> 本文件是落地说明：技能怎么记、怎么用、怎么变好、怎么退休。

## 一、思路来源

Hermes / Voyager 那一类 agent 的做法，掰开只有三步：

1. **成功后固化**：一次任务做通了，把「从目标到结果」的动作序列存成可复用技能，下次直接调，不重新推理。
2. **失败后反思**：失败了把原因写回技能（不是写进日记），同一个坑不踩第二次。
3. **检索后组合**：新任务先查技能库，命中就照着做，不命中才现场推。

我们这边的差别：Hermes 是单机单 agent，技能写在自己脑子里就行；我们有 33 个管家，所以技能必须是**共享库**，一处改、全体立刻受益。

## 二、四层落地

| 层 | 载体 | 谁写 | 作用 |
|---|---|---|---|
| 生成 | `tools/skill-new.sh` | 任何管家 | 生成结构完整的 SKILL.md 骨架（什么时候用/前置/步骤/验证/坑/回滚/来源） |
| 发布 | `/home/j/.openclaw/shared-skills` | 任何管家 | 单一主本，配置 `skills.load.extraDirs` 让 33 个管家共享 |
| 记录 | `tools/skill-usage.py use <技能> ok\|fail` | 使用者 | 每次用完记一次结果，进 `state/skills/usage.jsonl` |
| 优化 | `tools/skill-update.py <技能> "<补充>"` | 使用者 | 追加带日期的条目到指定小节，版本 +1，旧版存 `.history/` |

闭环：**用 → 记 → 发现失败 → 改技能 → 版本存档 → 再用**。

## 三、什么时候必须优化（硬性）

- 用技能时踩了坑、绕了路、或命令报错但最后做成了 → 立刻 `skill-update.py` 把「怎么绕的」写进「坑与注意」。
- 步骤里少了一条关键前提（比如需要 Windows 侧 cookie、需要 sudo）→ 写进「前置条件」。
- 同类失败累计 2 次以上 → 20:30 简报会出现 `▍技能` 一行点出来，看见就必须当天改。
- 同一领域出现第二个技能、内容 60% 重叠 → 合并成一个，另一个删掉（改旧的，不新建）。
- 45 天 0 次使用 → 候选退休，`skills-sync.sh --rm` 撤下（文件进 `_trash`，不硬删）。

## 四、版本与回滚

- frontmatter 带 `version` 与 `updated`，每次改自动 +1。
- 旧版本留在 `/home/j/.openclaw/shared-skills/.history/<技能>/v<旧版>-<时间>.md`（以 `.` 开头，不会被当成技能加载）。
- 改坏了：`cp .history/<技能>/v<旧版>-*.md <技能>/SKILL.md` 即回滚。
- 技能内容禁止出现密钥：`skill-new.sh --publish` 会扫 `sk-` / `ghp_` / 私钥头，命中直接拒发。

## 五、与 OpenClaw 原生 Skill Workshop 的关系

原生 `skill_workshop` 也支持「学习型技能 + 每次改动保留上一版 + undo」，但它写在**本 agent 私有目录**（`agents/<id>/agent/workshop-skills`），只有自己看得见。

我们的判断：
- 只影响我自己的操作习惯（比如我怎么读本机日志）→ 走 skill_workshop，私有即可。
- 影响多个管家（下载、打印、卸载软件、记账）→ 必须走 shared-skills，一处修全体受益。

## 六、日常操作（复制即用）

```bash
# 记录一次使用
python3 tools/skill-usage.py use windows-app-audit ok "卸掉雷电 120G"
python3 tools/skill-usage.py use windows-app-audit fail "UAC 卡住"

# 看哪些技能该改
python3 tools/skill-usage.py report

# 踩坑后立刻写回（版本 +1，旧版自动存档）
python3 tools/skill-update.py windows-app-audit "提权脚本要先 Stop-Process，否则卸载器会弹窗卡住"

# 看历史版本 / 回滚
python3 tools/skill-update.py --history windows-app-audit
```

## 七、验收口径

- `python3 tools/skill-usage.py report` 能报出使用次数、失败次数、待优化清单。
- 改一次技能后 `openclaw skills --agent cooking` 仍能列出该技能（改名/改坏会被立即发现）。
- 20:30 简报出现 `▍技能` 时，当天必须有一条 `skill-update.py` 记录。
