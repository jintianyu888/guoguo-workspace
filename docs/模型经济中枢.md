# 模型经济中枢（唯一入口）

主公令 2026-10-28 22:40：查余量、查优惠、模型使用与规划不许各算各的，必须捏成一件事。

## 一句话
所有模型经济相关的读、算、报，只走一条链：
```
tools/model-econ.sh  →  tools/model-ops.py  →  state/model-econ/econ.json（唯一真源）
```

## 子命令
- `model-econ.sh status` 一行一家，快查
- `model-econ.sh report` 唯一报表文本（信息窗/日报/看板都用它）
- `model-econ.sh refresh` 合并各采集器结果 → econ.json
- `model-econ.sh refresh-scrape` 先抓页再合并（定时任务用这个）
- `model-econ.sh verify` 一致性校验（订阅制禁止出现金额、禁止零兜底、必须有采集时间）

## econ.json 结构
- providers.<name>：kind(subscription/payg)、label、plan(名称/到期/自动续费)、quota(h5/week/month 百分比)、money_cny、unit、status、captured_at、source
- routing：默认模型、回退链、评审池（读 review-pool.json）
- derived：日耗、DeepSeek 跑道、余额序列
- alerts：跑道告警、额度告警、缺采集时间

## 口径铁律
- 订阅制（Kimi/MiniMax/GLM）：只报百分比与重置时间，**禁止折算金额**
- 预付（DeepSeek）：报余额与日耗、跑道
- 零值不许兜底：取不到就写未采集并进 alerts
