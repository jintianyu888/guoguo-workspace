## 四、管家自审格式（机器可读）

```

DONE|<今日完成项，分号分隔>
```

## 计划自动回流（2026-11-07 主公令）
- 任一任务**提前完成**后，后续计划自动前移：`tools/plan-reflow.py` 由 `tasks-db.py done` 自动调用（`--no-reflow` 可跳过）
- 规则：按原计划顺序重排，起点=现在+5分钟；工作窗口 08:30–22:30；红区 01:00–02:30 / 04:00–06:05 / 07:45–08:15 跳过；**只提前不推后**
- 固定时点项必须标 `pin_time=1`（等整夜批处理、等重启窗口、等主公拍板），否则会被误提前
- 手工查看：`python3 tools/plan-reflow.py --dry-run`
- 日历写入口：`python3 tools/calctl.py`（原 calendar.py 与标准库 calendar 撞名，已改名）

## 周末清账（2026-11-07 主公令 · 硬性）
- 除以下两类，**所有任务必须在周日 23:00 前做完并核验**：
  1) 需要主公亲自动手（`wait_user=1`，如重启 Windows、缴费、扫码）
  2) 周期性/计分任务（`kind in (periodic, score)` 或 grp 含「计分」）
- 主公明确冻结的任务（status=paused）不计入违规
- 执行工具：`tools/weekend-clear.py [--plan|--check]`，分类判定与逾期清单由它给出
- 三个简报（07:40/13:10/20:30）在周六日自动追加「周末清账」段；周日晚仍未清空则标「⚠ 未清空，今晚必须收口」
- 每项必须有可机器核验的 `verify` 命令；无 verify 的项在清单里标「缺验收」，不得直接关账（`done` 会拒）
- 违规处理：周日晚清单一并入逾期，次日 22:35 复盘必须逐条给原因
