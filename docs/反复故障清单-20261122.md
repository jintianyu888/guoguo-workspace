# 反复故障清单 · 2026-11-22（主公令：反复出现的故障都要建议根治）

> 规则：同一签名 30 天内出现 ≥2 次即入表；危险度按「丢数据 > 停服务 > 泄密 > 体验」排。
> 每次复发我会再提示一次，不再默默修掉。根治都要窗口，我不会自己动手。

## P0 危险（会丢数据/停服务/泄密，建议尽快根治）

### 1. 网关内存持续增长 → 事件循环停顿 → 全站卡住
- 现象：RSS 从 3.6G 一路涨到 17–19G；期间 60–105 秒事件循环停顿，管家全部超时。今天 16 次模型超时、面板横幅误报都源于此。
- 根因：Node 已分配未归还的堆 + 插件（memory-core）反复重载；重启只能清，不能治。
- 止血：重启网关（1–2 分钟，已有标准脚本）。
- 根治：加内存上限 + 定位插件重载触发条件（约 2 小时，需一次 08:00 窗口）。
- 复发：近 7 天 ≥5 次。首次记录 2026-11-21。

### 2. 面板零鉴权 + 任意命令执行（S0046，挂 346 小时）
- 现象：server.js 部分接口无鉴权即可触发命令；已有 IP 白名单缓解，但本机任意进程仍可调。
- 危险：等于给同网段一个后门；最坏被用来跑任意命令。
- 根治：接口级 token + 命令白名单（约 2–3 小时，可夜间做，需你批准）。
- 复发：长期未修，属「已知未治」。

### 3. 备份链路反复失败（9p ENOMEM / .part 时间戳 / 整目录 cp 超时）
- 现象：D→E 整目录 rsync 报 code 11/32；H 镜像用 cp 永远失败；保留策略曾因单盘失败整轮中止。
- 现状：已改成「只同步最新 + 后台单元 + 副本存在才删除」，11-22 手工验证 rc=0。
- 根治剩余项：9p 大文件传输改走 Windows 侧 robocopy 或分块（约 3 小时，需窗口）。
- 复发：本周 4 次（含误报）。

### 4. Code Mode 桥执行失败（#1064）
- 现象：管家用 Code Mode 调工具时 bridge tool_error，整轮判失败并弹「couldn't finish」。今天剧本杀管家多次。
- 止血：让该管家改走普通工具调用 / 给审批白名单。
- 根治：升级或改为非 Code Mode 执行（约 2 小时，需先在 B 机验证）。
- 复发：近 3 天 ≥3 次。

## P1 重要（影响可用性/可信度）

### 5. 飞书私聊白名单按应用隔离 → 机器人静默不回复
- 现象：主应用的 open_id 抄到别的应用等于没写；剧本杀管家因此完全收不到你的消息。
- 现状：已修（补该应用 open_id）。
- 根治：新建机器人时自动探测并写入（脚本化，1 小时）。
- 复发：本日 1 次（首次发现）。

### 6. 改执行权限不立即生效（工具策略会话快照）
- 现象：改完 safeBins/审批，老会话仍用旧策略，表现为「明明加了还是 allowlist miss」。
- 根治：改完自动提示「需新会话」；或给管家一个 reload 指令（1 小时）。

### 7. 定时任务被重启打成 interrupted/orphan，被误判失败
- 现象：job 只有 start 没有 end，统计成失败，触发假告警。
- 现状：已加自动标记 orphaned（2 小时阈值）并修正统计。

## P2 体验（不急，进半价窗）

### 8. 额度页拟人刷新单次 2.5–6.6 分钟，易被静默窗打断
- 根治：改零 token 直采接口（约 1.5 小时）。

### 9. 面板 /api/state 偶发 2–3 秒慢
- 原因：每次请求都触发全量刷新 + CLI 快照；已把快照周期 5→15 分钟。
- 根治：改增量缓存（约 2 小时）。
