# A3 骑马钉打印配方（2026-09-27 实测通过 ✅）

打印机：**TOSHIBA e-STUDIO**，`192.168.1.80:9100`（原始打印口）

## 一、血泪结论（通道真相）

| 组合 | 结果 |
|---|---|
| **PDF + PJL**（`ENTER LANGUAGE=PDF`） | ❌ **静默丢弃，一张不出** |
| **裸 PDF**（无 PJL） | ✅ 出纸，但**只能单面** |
| **PS + PJL**（`ENTER LANGUAGE=POSTSCRIPT`） | ✅ **完全可控**（A3/双面/长边）← **骑马钉走这条** |

## 二、骑马钉配方（已验证）

1. **纸张**：A3 横向（1190.55 × 841.89 pt）
2. **拼版**：页数补到 4 的倍数；每张 A3 = 两个 A4 面
   - 例（8 页）：正面 `[P8｜P1]`，背面 `[P2｜P7]`；第 2 张 `[P6｜P3]` / `[P4｜P5]`
3. **★ 背面整页旋转 180°** —— 不转就是颠倒的（主公实测确认 C 版正确）
4. **图像编码**：**1-bit 黑白 + 分条带（每 64 行一块）**
   - ❌ 不分条带 = **白纸**（实测）
   - 1-bit 比 RGB 小 8–24 倍，乐谱足够清晰
5. **PJL 头**（必须）：
```
@PJL SET PAPER=A3
@PJL SET DUPLEX=ON
@PJL SET BINDING=LONGEDGE
@PJL ENTER LANGUAGE=POSTSCRIPT
```
6. **分辨率**：150 DPI（乐谱够用）

## 三、工具

- `tools/pdf2ps.py` —— PDF → 可直推的 PS（1-bit + 条带 + 骑马钉 + 背面转180°）
  ```
  tools/asr-venv/bin/python tools/pdf2ps.py in.pdf out.ps \
      --dpi 150 --paper a3 --duplex long --booklet
  ```
  （`--pages N` 限页数；输出的 .ps **已是最终字节流**，直接 socket 送 9100，**不要再套 PJL**）
- `tools/booklet-ps.py` —— 纯数字试样（验页序用，带发送去重）

## 四、铁律（吃过亏）

1. **送印 ≠ 出纸** —— 必须看到纸才算完成
2. **同一任务只发一次** —— 重复投递 = 一堆废纸
3. **大活分张发** —— 单张 ≤ ~1.3MB 实测最稳
4. **遇异常先停手对齐** —— 不要闷头重发（主公 2026-09-27 指定）

## 五、实测记录（2026-09-27）

- ✅ A4 单页 1-bit 条带 → 出纸有内容
- ❌ A3 双面 1-bit **不分条带** → 白纸
- ✅ **A3 双面 1-bit 分条带（150DPI，1.3MB，4 页）→ 有乐谱**（主公确认）
## 六、主公实测观察记录（2026-09-27 14:21 / 14:27）

**同一张纸，两种翻法 → 两种读法**（左右会互换，属正常）：

| 纸 | 正面 | 背面（翻法一） | 背面（翻法二） |
|---|---|---|---|
| 第1张 | 左=空白 ｜ 右=封面 | 左=21 ｜ 右=26 | 左=26 ｜ 右=21 |
| 第2张 | 左=25 ｜ 右=22(无序号) | 左=23 ｜ 右=24 | 左=24 ｜ 右=23 |

**结论**：本机排版（正面 `[补白｜封面]`、背面 `[P2｜P7]`）与主公「翻法一」读法完全一致 ✅
**验收方式**：两张叠齐 → 对折 → 从封面翻：**封面 → 21｜22 → 23｜24 → 25｜26**

## 七、图片打印铁律（2026-09-27 血的教训）

- 手机截图常见 **1080×1528**，**必须放大到铺满 A4**（2480×3508 @300dpi）：
  `scale = min(2480/w, 3508/h)` → `im.resize(...)` ✅
- ⛔ **禁止用 `thumbnail()`** —— 它**只缩不放**，会把小图原样贴上，只占纸面约 43%（大白边）❌
- **打印前自检**：图像占纸面比例 **< 90% → 报警、不放行** ✅
- 乐谱/文档类，默认**左侧留 1cm 装订边**（可选）
