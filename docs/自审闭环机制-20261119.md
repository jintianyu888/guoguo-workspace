# 自审闭环机制 v1.0（2026-11-19 · 主公令：全链条改善，找更好的方法）

## 一、原来的链条与断点

事实包 12:20（零 token）→ 自审 agent 12:25/12:44/12:54/13:04/13:14 → 结论落盘 → 巡检 → 13:26 汇总 → 汇报

实测四个断点（11-18、11-19 两天都复现）：

1. **结论从不落盘**：任务提示词写「直接在回复里输出」，且明令「不要调用 exec/shell」，回复没有任何环节写进 `state/self-review/self-review-<date>.md`。五个管家两天的文件里都只有零 token 事实包，结论段为空。
2. **契约路径拼错**：backup / model 的契约写成 `state/self-review/<date>.md`，实际文件是 `self-review-<date>.md`，于是永远「无产物」。
3. **巡检不看时点**：12:30 巡检时，12:44/12:54/13:04/13:14/20:30/23:20 的活都还没到点，一律判 ❌。
4. **只看大小不看内容**：事实包本身就有 800B 上下，正好骗过 `min_bytes=800`，形成假绿。

## 二、新做法（不靠 agent 自觉，改从系统侧收割）

核心判断：**agent 的回复本来就存在 cron 运行记录里**（`openclaw cron runs` 的 summary，实测 6KB+ 真内容）。让模型再调一次工具去写文件，既费 token 又受 allowlist 限制；不如由脚本把已有回复收割进文件。

- `tools/selfreview-harvest.py`（新增，零 token）
  - 按任务名映射到 5 个管家工作区，取当日最近一次成功运行的 summary；
  - 追加为 `## 结论（agent 自审 · 运行于 MM-DD HH:MM）` 段，带 `<!-- harvest:ts -->` 指纹；
  - 幂等：同一轮运行只写一次（状态在 `state/butler/harvest-state.json`）；
  - 13:25 之后仍缺结论的，直接进夜间汇总队列，不静默。
- `oc-selfreview-harvest.timer`：每日 13:15、13:25 两轮（覆盖最晚的 hermess 13:14 与迟到重跑）。
- `tools/butler-duty.py` 三态化：
  - `✅` 产物达标且含 `## 结论`；
  - `⏳未到点` 时点没到，不算缺、不计数；
  - `⚠空壳` 文件在但没结论段 —— 这才是「产出没落地」。
- `state/butler/contracts.json`：backup / model 的 selfcheck 路径改回 `self-review-<date>.md`。
- `tools/rules.json` 新增 R12「五管家自审结论当日落盘」，检查命令就是 `butler-duty.py` 的退出码，每天开工闸门自动跑。

## 三、验证

- 收割实测：12:50 手动跑，maint +703B、backup +2069B，内容是真结论（例：备份管家指出「群晖副本未更新、队列 7 连败」「10-31 单副本 19 天，盘坏即丢」）。
- 幂等实测：再跑一次全部 SKIP，不重复写。
- 巡检实测：14 项达标、0 不达标；backup 由「假缺」变为如实「空壳」，收割后转 ✅。
- 规则实测：R12 ✅（同批跑出 R10 淘金币红，属既有问题，不在本次范围）。

## 四、回滚

- 契约：`state/backup/config/contracts.json.bak-dutyfix-20261119`
- 巡检器：`state/backup/config/butler-duty.py.bak-duetime-20261119`
- 规则表：`state/backup/config/rules.json.bak-R12-20261119`
- 停收割：`systemctl --user disable --now oc-selfreview-harvest.timer`
- 收割脚本本身只追加、带指纹，删掉对应段落即可复原。

## 五、这条链上还值得继续改的（下一步）

1. **产出落盘通用化**：目前只修了自审这一条。凡是「agent 回复即产物」的任务（互审、日报、体检），都该走收割而不是要求模型写文件。可做一个 `output-harvest` 通用器 + 任务表。
2. **巡检时点对齐**：巡检每小时整点/半点跑，本身没问题；真正该做的是把「未到点」从告警口径里彻底摘掉（本轮已做）。
3. **空壳率进周报**：连续 3 天出现空壳的管家，按空转规则降级，不让它一直占着 5 个自审位。
