# 每日淘宝淘金币自动化 v2（2026-11-15）

## 一、为什么改
- 旧链路：oc-phone-tasks.timer（每 15 分钟探一次，日内随机时刻）→ tools/phone-tasks-daily.sh → 小米「Kola助手」一键执行任务（淘金币/淘宝签到/芭芭农场）
- 11-15 18:15 失败：`ERROR 一键执行任务 not found`（rc=3）。Kola 新版首页已无该按钮，只剩图标宫格。
- 叠加问题：Kola 的无障碍服务被 HyperOS 反复回收（`settings get secure enabled_accessibility_services` 常为 null，dumpsys accessibility 显示 Enabled services:{}），即使用 settings put 写入也会被清掉；无权限时点图标只弹「请开启相关权限」。
- 另有两个隐蔽坑（都已写进脚本注释）：
  1) Kola 常驻悬浮窗 → `uiautomator dump` 抓到的是 Kola 窗口而不是淘宝，导致元素找不到；
  2) `adb shell cat /sdcard/xx.xml` 会截断/失败，必须 `adb pull`。

## 二、现在的链路（已验证）
```
oc-phone-tasks.timer (*:0/15)
  └─ oc-phone-tasks.service → tools/phone-tasks-daily.sh   # 日内随机时刻闸门（07:00-23:00）
       └─ tools/taobao-coin.sh                              # v2.1
            1 force-stop com.xiaomi.gamecenter（清悬浮窗）
            2 亮屏+解锁 → force-stop 淘宝 → monkey 拉起
            3 dump 找「领淘金币」(content-desc) → 点；找不到则固定坐标 112,437 兜底
            4 dump 验证页面出现「连签」→ 截图取证 → rc=0
```
- 失败不标 done，最多重试 3 次（plan.json attempts），避免死循环也避免「一次失败全天不补」。
- 产物：state/phone/taobao-coin.json（last_run/ok/evidence）、taobao-coin-latest.png、taobao-coin.log、scheduler.log、plan.json。
- 规则：rules.json R10「每日淘金币已签（24h 内成功一次）」，开工闸门自动核。

## 四、坑与注意
- 手机必须 USB 连着（adb 走 Windows 版 adb.exe，路径 tools/adb.sh 封装）；不在线时脚本 rc=2。
- 淘宝未登录 / 需滑块验证时脚本会 rc=4，要人工处理一次。
- 淘金币「每日签到」在进入页面时自动完成，脚本只需确保进入页面。
- 芭芭农场、淘宝签到等 Kola 任务目前**没有**自动跑了（Kola 权限路线断了）；需要的话按同样思路加直连淘宝的脚本。

## 五、回滚
- 恢复旧链路：`sed -i 's#bash "$SCRIPTS/taobao-coin.sh"#python3 "$SCRIPTS/phone-kola-task.py"#' tools/phone-tasks-daily.sh
- 或直接 `systemctl --user disable --now oc-phone-tasks.timer`（停掉每日任务）
- 规则回滚：从 tools/rules.json 删除 R10
