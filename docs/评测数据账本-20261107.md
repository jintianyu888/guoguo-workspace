## 三、归一后的能力
- 一条 SQL 查"某模型所有评测"：`select ts,suite,score,score_max,latency_s,evidence from runs where model='MiniMax-M3' order by ts`
- 一条 SQL 查"某评审员有效产出率"：`select provider,model,count(*),sum(verdict!='FAILED' and verdict!='UNKNOWN') from reviews group by 1,2`
- 提案分歧可直接筛：同一 proposal 同时出现 APPROVE 与 REJECT 的 5 组（20261030-2010-alertgate、20261101-144412、20261101-180832、20261102-031500、20261102-201318）
- 失败可回溯：272 次评审里 51 次是 FAILED（网关超时/鉴权/额度），其中 2026-10-27 当天 zhipu 25 次全挂——那是网关超时事故，不是模型差

3. **评审失败率高**：19%（51/272），全部集中在 10-26 → 10-27 的网关抖动窗口
4. **提案汇总口径粗**：md 表只有"2/2 全部完成"，没有记录"两家判定是否一致"
