- 会断 20–30 秒，重启后我立刻验：版本、端口、Feishu 收发、内存回落到 ~1GB

**选项 B（长期，需 sudo）— 加内存上限**
```bash
mkdir -p ~/.config/systemd/user/openclaw-gateway.service.d
cat > ~/.config/systemd/user/openclaw-gateway.service.d/memory.conf <<'EOF'
[Service]
MemoryHigh=3G
MemoryMax=3.5G
EOF
systemctl --user daemon-reload && systemctl --user restart openclaw-gateway
```
代价：超限会被内核压/杀，表现为偶发重启；好处是有硬天花板。

**我的建议**：先 A（今晚或明早），观察 24 小时；还涨到 4G 以上再上 B。
