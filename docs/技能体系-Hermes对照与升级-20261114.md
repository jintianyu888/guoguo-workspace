## 一、Hermes 到底怎么"成功即记录"

1. **创作提示（nudge）**：`agent/agent_init.py` 里 `_skill_nudge_interval = 10`、`_memory_nudge_interval = 10`。每 10 次工具调用/10 轮对话，系统在上下文里插一条"考虑把刚才的流程存成技能"的提醒，不是等它自觉。
2. **回合后后台复盘线程**：`agent/background_review.py`，config 里叫 `background_review`，回合结束在 daemon 线程里跑一次独立复盘，直接写 skills/ 与 memories；用量记在 `session_model_usage task='background_review'`。
3. **/learn 命令**：`agent/learn_prompt.py`。用户说"学一下这个"（目录、URL、刚才的对话、粘贴的笔记），agent 自己去取源、按技能写作标准落盘。
4. **写作标准**：SKILL.md 100 行（简单）/200 行（复杂）内；正文只留索引与用法，大材料进 `references/`、脚本进 `scripts/`；禁止写"只指向别的技能的hub技能"；**已有近义技能必须补旧的，不许建重复**。
5. **frontmatter 字段**：name / description / version / author / license / platforms / metadata.hermes.tags / related_skills。
6. **目录分级**：12 个类别（apple、creative、devops、software-development、research、web…），每类一个 `DESCRIPTION.md`，44 个技能；类别描述先给模型看，具体技能按需加载。
7. **Curator 生命周期**（`agent/curator.py`）：闲置 2 小时且距上次巡检 ≥7 天时触发；**14 天未用 → stale，30 天未用 → archived**；只归档不删除（可恢复）；pinned 技能豁免；LLM 合并默认关闭（`DEFAULT_CONSOLIDATE = False`）。
8. **使用统计**：`tools/skill_usage.py` 记录每次加载/使用，curator 依此判闲置。
