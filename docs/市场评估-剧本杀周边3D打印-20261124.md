# 市场评估：剧本杀周边 3D 打印（2026-11-24）

> 问题：同类多不多、有没有市场、我们能不能做。

## 一、结论（先说）
1. **不是蓝海，是"供给少且需求更少"**。同类 3D 打印道具几乎无人做，不是因为没人想到，而是因为店家不为此花钱。
2. **行业在结构分化**：注册门店约 4.85 万家，但真正有交易的活跃门店仅 2.5–3 万家（2021 年峰值 4.5 万）；规模仍在涨，门店在关。沉浸式实景/剧场在增长，传统盒装店在收缩。
3. **3D 打印在"标品"上没有成本优势**：义乌同类道具批发 3–10 元，我们打印一件成本 15–30 元。标品必输。
4. **唯一有戏的是三块**：B 端机关定制（含建模 300–1500 元/件）、通用道具补充包（不绑 IP）、桌游/TRPG 配件（盘子更大、复购更强）。

## 二、需求侧证据
- 按剧本打包道具包：159 元，已售 **13 件**（小黑探平台，含铃铛/花绳/徽章 36 个等；平台标注淘宝原价合计 239 元）。
- 单品：北极星主题合金手环（带钥匙机关）28.4 元；汉剑竹木道具百元内。
- 闲鱼主要是**关店清货转卖**（2021 年 4 月"倒闭了"转卖量环比 +110%），说明二手供给多、专业卖家少。
- 采购含义：淘宝适合标准化单品，闲鱼适合低价淘非标；**但单款 13 件的销量说明店家采购频次极低**。

## 三、供给侧
- 淘宝/1688 的剧本杀道具以义乌小商品、手工布景、服装为主，**没有成规模的 3D 打印道具卖家**。
- 3D 打印在这个品类的空白，原因是价格而不是技术。

## 四、真正的机会（按可行性排序）
1. **B 端机关定制**：暗格木盒、密码转盘、机关锁、可开合的证物箱。单价 300–1500 元（含建模），毛利高、量小，靠本地店家口碑。适合我们的设备与建模能力。
2. **通用道具补充包**（不绑 IP）：仿古钥匙、怀表、毒药瓶、印章、筹码、线索卡架、人物立牌底座。打包卖 99–299 元，可先在本地 3–5 家店试。
3. **桌游/TRPG 配件**：骰子塔、卡牌盒、token、地形件。玩家复购强、可跨境（Etsy 上同类 10–40 美元）。
4. 玩家向纪念周边：角色徽章、剧本纪念牌——单价低、复购低，不建议做主。

## 五、红线
- **剧本 IP 归属发行方**，做剧中角色/logo 周边需授权；只做通用道具与自有设计。
- 不仿制他人已注册外观设计的机关道具。

## 六、7 天验证（成本 <100 元）
1. 打 1 个机关盒样件（暗格+转盘，PLA，约 6–8 小时，材料 <20 元）。
2. 拿给本地 2–3 家剧本杀店看反应，问三个问题：愿不愿买、出多少钱、还缺什么道具。
3. 同时挂 1 个"通用道具包"到闲鱼试水（用现有小件拍照，不必先量产）。
4. 判据：≥2 家店愿意付定金 或 ≥1 单线上成交 → 继续；否则只保留机关定制这一条，不铺货。

## 七、未采集
- 剧本杀行业 2025 年市场规模具体金额（公开口径分歧大）。
- 店家年均道具采购预算。
- 3D 打印道具的实际成交案例（检索未见）。

## 八、角色名字牌位的版权问题（2026-11-24 追加）

### 1. 风险来自哪里（关键：不是著作权，是反不正当竞争）
- **角色名称本身短，一般不构成独立作品**，著作权很难单独主张。
- 但**反不正当竞争法第六条**管得住：角色名经使用形成"有一定影响的商品名称"，他人在商品实物或销售页面突出使用、导致来源混淆，即构成仿冒。
- 判例：《蔚蓝档案》角色手办案（上海长宁法院，2026 年审结）——被告在拼多多卖手办，标题直接用"砂狼白子""天雨亚子"，被判反法第六条混淆，判赔 15000 元。法院并未支持"复制角色形象"的主张，**仅凭在标题/页面使用角色名就认定了混淆**。
- 类案：《陈情令》周边网店案——标题用剧名+角色名，同样被诉。
- 另一层是商标：发行方可能已把剧本名/角色名注册在第 28 类（玩具）或第 16 类（纸品）。

### 2. 分场景判断
- 只做**空白牌位**（无字，客户自己贴/自己刻）：风险最低，属加工承揽。
- 做**通用功能位**（老爷/夫人/管家/医生/侦探/管家）：无特定作品指向，安全。
- 做**特定剧本角色名**并对外销售：风险高，尤其标题、包装、详情页出现"XX剧本同款""XX角色"。
- 做**角色立绘/剧本 logo/门派纹样**：直接侵犯美术作品著作权，绝对不要碰。

### 3. 推荐做法（按安全度排序）
1. **B 端代工**：店家下单，提供文字与授权保证，我们只负责建模与打印。合同写明"图样及文字由甲方提供，甲方保证权利合法，侵权责任由甲方承担"。这是印刷厂模式，最稳。
2. **空白 + 刻字服务**：卖无字牌位套装，刻字由店家自己完成或下单时提供文字。我们不主动使用任何剧本名/角色名做营销。
3. **拿授权**：直接找发行方谈周边授权，小发行通常愿意分成（常见 10–20%），拿到书面授权后再做专属款。
4. 若一定要做角色名：商品标题与包装**不出现作品名**，只写"定制席位牌/角色牌"，并且在订单备注中记录由客户提供文字。

### 4. 平台与民俗注意
- 淘宝/小红书对"牌位"字样审核敏感，用"席位牌""角色名牌""立牌"表述，避免"灵位""祭祀"。
- 不要用"官方""正版""授权"等词，除非真有授权文件。

### 5. 一句话
名字本身告不到你，**但"用别人的名字卖货"会被认定为搭便车**。所以商业模式要设计成"我们卖空白件和加工能力，名字由店家提供"。

## 九、人物形象做手办 / 挂剧本杀名字卖周边（2026-11-24 追加）

### 1. 角色形象做手办：直接侵权，没有模糊空间
- 角色立绘、人物设定属**美术作品**；做成手办是"从平面到立体"的复制，落入复制权、发行权；改动造型还涉及改编权。
- 《蔚蓝档案》案中，法院除认定标题使用角色名构成混淆外，还认定手办与角色形象**实质性相似**，侵害发行权与信息网络传播权，一并判赔。
- 即使剧本没有官方立绘，DM 或画师画的同人图也有著作权（归画师）；照抄一样侵权。
- 结论：**没有书面授权，一律不做。**

### 2. 挂"剧本杀+名字"卖周边：三重风险叠加
- 商标：发行方常把剧本名/角色名注册在第 28 类（玩具）、第 16 类（纸品）。
- 反不正当竞争法第六条：标题、包装、详情页突出使用知名剧本名，构成混淆。
- 虚假宣传：写"官方""正版""授权"而无授权文件，属虚假宣传，平台可直接处罚。
- 平台侧还会主动下架并扣分，账号风险大于单笔利润。

### 3. 设备现实的硬约束
- 我们手上的 P2S 是 **FDM**，层纹明显，做 6–10cm 手办卖不上价；精细手办需要**光固化树脂**，需另购设备与后处理（清洗、固化、上色）。
- 所以"角色手办"这条，法律和设备两道门都过不去。

### 4. 可行的替代（零 IP 风险，客单更高）
1. **真人形象手办**：客户提供照片 → 建模 → 打印 → 上色。市场价：无现成模型约 2000–3000 元，有模型 1000–1500 元，仅代打约 288 元；成品尺寸集中 6–10cm。零版权风险（客户本人肖像，需签肖像使用同意）。
2. **授权代工**：为发行方生产官方周边，赚加工费，拿书面授权。
3. **通用道具**：机关盒、席位牌（空白）、筹码等，不涉及形象。

### 5. 一句话
**形象不能碰、名字不能挂；能碰的是"人"——玩家自己、DM 自己。** 做真人定制，法律干净，客单还是角色手办的 3–10 倍。

## 十、钢琴周边（2026-11-24 追加）

### 1. 法律面：确实干净得多
- 钢琴周边是通用功能件，没有角色/剧本 IP，主要风险只剩三类：
  - **商标**：Yamaha、Steinway（施坦威）、Bösendorfer 等 logo 不能打，也不能暗示"原厂"。
  - **外观设计专利**：手型矫正器、踏板增高器、谱夹这类成熟件，可能有人注册外观设计。
  - **实用新型**：某些带结构的矫正器/机关件。
- 自查办法：CNIPA 外观设计检索（免费）按关键词查一遍；拿不准就改结构、改比例，做出可见差异。

### 2. 市场面：需求真实，但标品打不过义乌
实测价格与销量（2026 年页面）：
- 琴键贴 3.6–37.6 元；1688 有链接成交 10 万+ 件。
- 手型矫正器 22–52 元（标价 58–120），第三方数据称累计 3.8 万件。
- 踏板增高器 198–388 元；淘宝某木制款已售 1 万+ 件。
- 谱夹 6–24 元；节拍器 37–146 元（拼多多某款已拼 5000+）。
- 琴凳垫 10–60 元；识谱教具 13–70 元，但销量普遍"已售 100 以内"。
- 结论：**能被注塑/义乌做的件，价格已经压到个位数到几十元，3D 打印没有成本优势。**

### 3. 3D 打印真正有优势的四类
1. **老旧钢琴缺失配件修复**：原厂停产、标品买不到——琴键、卡钉、装饰件、踏板零件。单价 30–150 元，毛利高，且客户没得选。
2. **按尺寸定制**：儿童手型辅助器（按手大小）、琴凳增高/脚垫（按身高）、谱架加宽加高件。
3. **特定型号适配件**：电钢琴接口盖、防尘塞、耳机挂钩、线夹——型号多、单品量小，开模不划算。
4. **教学场景专用件**：班级用大号识谱板、手指号牌、节奏卡座、节拍分组牌——学校里买不到，只能定制。

### 4. 不建议做的
- 琴键贴、节拍器、普通谱夹、矫正器标品——义乌已经做穿，做了也是陪跑。
- 任何带品牌 logo 的件。

### 5. 建议路径（三步）
1. **自用先行**：先给自家机构做 5 件（大号识谱板、手指号牌、琴凳增高垫、谱架加宽件、踏板辅助块），零风险、立刻能用、还能当样品。
2. **本地 B 端**：找 2–3 家琴行/调律师，主打"停产配件修复 + 定制件"，客单 50–300 元。
3. **线上只卖定制**：闲鱼挂"钢琴配件定制/修复"，不挂标品，避免比价。

### 6. 一句话
**钢琴周边版权风险低，但商业上赢的不是"周边"，是"定制与修复"。** 标品是义乌的战场，非标才是我们的。

## 十一、钢琴八音盒（2026-11-24 追加）

### 1. 市场：有，但是礼品红海
价格分层（淘宝 2026 页面）：
- 装饰/玩具级 20–60 元。
- 木质刻字 / 18 音基础款 150–320 元。
- 30 音及以上或水晶/玻璃款 800–1600 元。

爆款证据（拼多多）：
- 若客若态 DIY 拼装钢琴八音盒 115 元起，已拼 5000+ 件。
- 雷曼士水晶钢琴八音盒 498 元起，已拼 5000+ 件。

判断：需求真实（礼品、生日、毕业、情人节），但供应链在义乌/宁波已经成熟，**标品靠流量与成本，我们两样都不占**。

### 2. 成本结构（关键，决定能不能做）
- 18 音机芯批发：手摇基础款 3.2–3.7 元（起订 100）；发条款 4–6 元（100–1000 件）；带支架 6–7 元（1000 件起）；镀金 15 元。
- 30 音/50 音机芯与定制曲目打样费、起订量：**未采集**（需直接问供应商）。
- 我们的单件成本估算：机芯 5 + 耗材 5–15 + 后处理工时 → 约 20–30 元（不含人工）。

### 3. 3D 打印的劣势要说清楚
- 质感打不过实木、亚克力、水晶；FDM 层纹明显，要打磨喷漆才有卖相。
- 所以不能做"高端摆件"，只能做"设计感 + 定制 + 拼装"。

### 4. 可做的窄切口（三条）
1. **DIY 拼装款**：拼多多 115 元已拼 5000+ 证明拼装受欢迎；3D 打印天然适合小批量拼装件，可做"可拆装钢琴 + 齿轮联动"。
2. **定制刻字 + 公版曲目**：孩子名字/日期刻字，曲子用公版古典（作者去世满 50 年），规避词曲版权。
3. **机构礼品（B 端）**：结业礼、比赛奖品、考级纪念。我们自己就是渠道，先做 30 件自用验证，再卖同行。

### 5. 版权红线
- **曲目**：流行曲 = 词曲著作权（机械复制/发行），不要用；公版古典安全。
- **外观**：钢琴通用造型难被垄断，但不要打 Steinway/Yamaha logo，也不要照抄知名品牌的注册外观。
- **音乐 IP 联名**：没有授权不做。

### 6. 结论
有市场，但**不是好生意的主线**；作为"机构礼品 + 定制刻字"的小切口可以做，客单 68–128 元，批量 30–50 件起，毛利 50% 左右。标品摆件不要碰。

### 7. 7 天验证（成本 <100 元）
1. 买 3 个 18 音机芯（约 20 元），打 1 个拼装式钢琴外壳。
2. 装一支公版曲，拍 15 秒视频（拆装 + 播放）。
3. 给 5 位家长/同行看，问：愿不愿买、多少钱、送什么人。
4. 判据：≥2 人愿意付 99 元以上 → 做小批量；否则只留作机构自用礼品。
