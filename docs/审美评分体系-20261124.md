# 审美评分体系（2026-11-24 立）

## 为什么这么做
主公原话：「审美我也不准，你先按我的评分体系来做，以后我告诉你哪个好看哪个丑。」
设计成三层：机器先筛（快、免费、稳定）→ 通用分 → 主公反馈逐步覆盖成「你的口味」。

## 四件套
1. 标准：把「好看」拆成可测维度（清晰度/对比度/色彩丰富度/对称/主体突出/曝光缺陷/分辨率）
2. 锚点：参考图库（CLIP 相似度），没有锚点就只算通用分
3. 裁判：LAION 美学 v2（1-10 分）+ 客观指标 + 主公 good/bad 反馈
4. 闭环：批量出 → 排序 → 取前 N → 再变异 → 主公一句话反馈入库

## 工具
tools/aesthetic.py（本地、零 token）

score <文件或目录> [--top N] [--json] [--ref 参考目录]：打分排序，结果累加进 state/aesthetic/scores.jsonl
feedback <图> good|bad [--note 说明]：记录主公判断，进 state/aesthetic/feedback.jsonl
calibrate：≥8 条反馈后拟合个人偏好（逻辑回归），权重存 state/aesthetic/model.json
stats：看样本量与校准状态

## 分数口径
base = 0.55 × LAION + 0.25 × 技术分 + 0.20 × 构图分（曝光缺陷扣分）
personal = 逻辑回归概率（未校准时为空）
final = 有校准 0.45×base + 0.55×personal；无校准 = base

## 各方向用法
生图：一次出 4 张 → score → 前 2 细化变异
3D 打印：Blender 出三视图/转台渲染 → score → 同时看 Orca 切片预览
剪辑：PySceneDetect 切镜 → 抽帧 score → 挑封面/看节奏密度
音乐：librosa 对参考曲做数值对比（频谱重心/动态/节拍密度/LUFS）

## 局限（必须知道）
LAION 训练数据偏摄影，扁平图标/渲染图普遍 3-4 分 → 只看同类相对排序，不做跨类比较
无参考库时只算通用分，判断不了「像不像你要的风格」
反馈 <8 条时 calibrate 会拒绝，禁止拿两三条样本宣称学会了口味

## 回滚
删除 tools/aesthetic.py 与 state/aesthetic/ 即完全撤除，不影响其它链路。
