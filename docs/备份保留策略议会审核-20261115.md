## 结论（2/3 席位一致，L2 有效）
1. 自动删除**不上线**；只保留每月预演 + 账本校验 + 告警
2. 份数采纳较保守一组：X 7 / D 3 / E 每周1×4 / H 每月1×3 / NAS 每日7
3. 每盘最低 2 份，低于即中止（rc=9）
4. 删除仅允许单盘显式执行，`all` 直接拒绝（rc=8）
5. 目标盘无原生回收站/快照 → 不执行自动删除；目前 X/D/E/H 经 WSL 删除均绕过回收站，NAS 未开 #recycle，因此**自动删除实际处于永久关闭状态**，删除须逐次人工批准
